# Day 1 production

## Confirmed decisions

- English narration, using a neutral synthetic stock/demo voice.
- OBS Studio screen recording of VS Code, explicitly approved after Astra IDE was not found. Use the isolated `Python30Days-Day01` OBS profile.
- GPT-6 Sol handles capture, audio integration, technical graphics, and timeline engineering. YouTube editorial agents use GPT-5.6 Sol.
- Deliverable: Day 1 video, editable DaVinci Resolve timeline/project, and source assets.
- Target: 1920×1080, 30 fps, Rec.709, H.264 MP4, 48 kHz audio.

## Visual direction

Dark charcoal background; warm yellow labels; restrained blue highlights. Keep code and output large enough to read at 1080p. Technical state changes use short stepped fades, with blur-in/blur-out limited to transitions. Smooth easing is appropriate for framing and explanatory motion; the readable state must remain sharp.

Use genuine editor recordings for demonstrations. HyperFrames graphics explain relationships and provide context; they must not be presented as an IDE capture. Any generated illustrative image must be identified in the asset manifest by its actual source.

Do not replace missing demonstration footage with unrelated loops to conceal a gap. Missing captures, unavailable image-generation tools, or blocked Resolve access must remain explicit in the production report.
