
Pandas

Pandas is an open source, high-performance, easy-to-use data structures and data analysis tools for the Python programming language.
Pandas adds data structures and tools designed to work with table-like data which is Series and Data Frames.
Pandas provides tools for data manipulation:


reshaping

merging

sorting

slicing

aggregation

imputation


If you are using Anaconda, you do not have to install pandas.

For Windows:
terminal

You can also install pandas alone with pip install pandas.

Pandas data structure is based on Series and DataFrames.

A series is a column and a DataFrame is a multidimensional table made up of a collection of series. In order to create a pandas series we should use numpy to create a one dimensional array or a python list.

Importing Pandas
example.py
import pandas as pd  # importing pandas as pd
import numpy as np   # importing numpy as np

1. Creating Pandas Series with Default Index
example.py
nums = [10, 20, 30, 40, 50]
s = pd.Series(nums)
print(s)


View:
output.txt

1    20
2    30
3    40
4    50
dtype: int64


The left column is the index (0 to 4). The right column is the data. dtype: int64 means the values are integers.

The original lesson used [1, 2, 3, 4, 5]. Same syntax:

As you can see in the DataFrame above, we did add new columns, Weight and Height. Let us add one additional column called BMI (Body Mass Index) by calculating BMI from mass and height. BMI is mass divided by height squared (in meters): Weight / (Height * Height).

The height is in centimeters, so we should change it to meters. Let us modify the height column.

18. Modifying column values
example.py
df['Height'] = df['Height'] * 0.01
print(df)


View:
output.txt
    Name Country       City  Weight  Height
0  Priya   India  Hyderabad      74    1.73
1  Arjun      UK     London      78    1.75
2   Maya  Sweden  Stockholm      69    1.69


173 * 0.01 = 1.73. Every row is updated at once. No for loop.

Using a function makes the BMI code clean, but you can calculate BMI without one.
example.py
def calculate_bmi():
    weights = df['Weight']
    heights = df['Height']
    bmi = []
    for w, h in zip(weights, heights):
        b = w / (h * h)
        bmi.append(b)
    return bmi

bmi = calculate_bmi()
df['BMI'] = bmi
print(df)


View:
output.txt
    Name Country       City  Weight  Height        BMI
0  Priya   India  Hyderabad      74    1.73  24.725183
1  Arjun      UK     London      78    1.75  25.469388
2   Maya  Sweden  Stockholm      69    1.69  24.158818


Vector form of the same formula (no loop):
example.py
df['BMI'] = df['Weight'] / (df['Height'] * df['Height'])
