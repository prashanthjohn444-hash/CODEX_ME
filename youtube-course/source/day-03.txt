Let us start connecting the dots and start making use of what we already know to calculate (area, volume, density, weight, perimeter, distance, force).

Example:
example.py
# Calculating area of a circle
radius = 10                                 # radius of a circle
area_of_circle = 3.14 * radius ** 2         # two * sign means exponent or power
print('Area of a circle:', area_of_circle)

# Calculating area of a rectangle
length = 10
width = 20
area_of_rectangle = length * width
print('Area of rectangle:', area_of_rectangle)

# Calculating a weight of an object
mass = 50
gravity = 9.81
weight = mass * gravity
print(weight, 'N')                         # Adding unit to the weight

# Calculate the density of a liquid
mass = 50      # in Kg
volume = 0.05  # in cubic meter
density = mass / volume  # 1000 Kg/m^3
print(density, 'Kg/m^3')


View:
output.txt
Area of a circle: 314.0
Area of rectangle: 200
490.5 N
1000.0 Kg/m^3


** is done before *, so 3.14 * radius ** 2 is 3.14 * (10 ** 2), not (3.14 * 10) ** 2.

Example: Comparison Operators
example.py
print(30 > 20)     # True, because 30 is greater than 20
print(30 >= 20)    # True, because 30 is greater than 20

print(30 != 20)    # True, because 30 is not equal to 20
print(len('Priya') == len('Rao'))          # False  5 == 3

print(len('city') == len('Rao'))           # False  4 == 3

Identity and Membership Operators

In addition to the comparison operators above, Python uses identity operators and membership operators.

Identity operators:




  Operator
  Description
  Example





  is
  Returns true if both variables are the same object
  x is y



  is not
  Returns true if both variables are not the same object
  x is not y




Membership operators from the original lesson prose:




  Operator
  Description
  Example





  in
  Returns True if the queried list (or string) contains a certain item (x in y)
  'P' in 'Priya'



  not in
  Returns True if the queried list (or string) does not have a certain item (x not in y)
  'Z' not in 'Priya'



example.py
print('1 is 1', 1 is 1)                   # True - because the data values are the same object
print('1 is not 2', 1 is not 2)           # True - because 1 is not 2
print('P in Priya', 'P' in 'Priya')       # True - P found in the string
print('B in Priya', 'B' in 'Priya')       # False - there is no uppercase B
print('code' in 'code for all')           # True - because code for all has the word code
print('a in an:', 'a' in 'an')            # True
print('4 is 2 ** 2:', 4 is 2 ** 2)        # True
print('H in Hyderabad', 'H' in 'Hyderabad')
print('Z not in India', 'Z' not in 'India')
print(10 in [10, 20, 30, 40, 50])
print(60 not in [10, 20, 30, 40, 50])


View:
output.txt
1 is 1 True
1 is not 2 True
P in Priya True
B in Priya False
True
a in an: True
4 is 2 ** 2: True
H in Hyderabad True
Z not in India True
True
True


== compares values. is compares identity (the same object in memory). Prefer == for numbers and strings. Python may warn when you write 1 is 1 because small literals are an implementation detail. Membership (in / not in) works on strings, lists, and other collections.

Logical Operators

Unlike other programming languages Python uses keywords and, or and not for logical operators. Logical operators are used to combine conditional statements. Every row is written here.




  Operator
  Description
  Example





  and
  Returns True if both statements are true
  x < 5 and x < 10



  or
  Returns True if one of the statements is true
  x < 5 or x < 4



  not
  Reverse the result, returns False if the result is true
  not(x < 5 and x < 10)



example.py
print(30 > 20 and 40 > 30)  # True - because both statements are true
print(30 > 20 and 40 < 30)  # False - because the second statement is false
print(30 < 20 and 40 < 30)  # False - because both statements are false
print('True and True: ', True and True)
print(30 > 20 or 40 > 30)   # True - because both statements are true
print(30 > 20 or 40 < 30)   # True - because one of the statements is true
print(30 < 20 or 40 < 30)   # False - because both statements are false
print('True or False:', True or False)
print(not 30 > 20)     # False - because 30 > 20 is true, then not True gives False
print(not True)        # False - Negation, the not operator turns true to false
print(not False)       # True
print(not not True)    # True
print(not not False)   # False


View:
output.txt
True
False
False
True and True:  True
True
True
False
True or False: True
False
False
True
True
False


and needs both sides True. or needs one side True. not flips True to False and False to True.
