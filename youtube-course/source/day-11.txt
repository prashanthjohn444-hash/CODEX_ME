
Functions

So far we have seen many built-in Python functions. In this section we write custom functions. What is a function, and why do we need them?

Defining a Function

A function is a reusable block of code designed to do a certain task. To define (declare) a function, Python uses the def keyword. The function body runs only when the function is called (invoked).

The numbered constructs below keep every function pattern from the original lesson: no parameters, return, one parameter, two parameters, keyword arguments, default values, *args, ** unpacking, **kwargs, and passing a function into another function. Example values use 10, 20, 30, 40, 50 and Priya / Hyderabad.

1. Declaring and Calling a Function

When we write a function we declare it. When we use it we call or invoke it. Functions can be declared with or without parameters.
example.py
# syntax
# Declaring a function
def function_name():
    codes
    codes
# Calling a function
function_name()


The def line names the function. The indented block is the body. The name followed by () is the call.

2. Function without Parameters

A function can be declared without parameters.

Example:
example.py
def generate_full_name():
    first_name = 'Priya'
    last_name = 'Rao'
    space = ' '
    full_name = first_name + space + last_name
    print(full_name)

generate_full_name()  # calling a function

def add_two_numbers():
    num_one = 10
    num_two = 20
    total = num_one + num_two
    print(total)

add_two_numbers()


View:
output.txt
Priya Rao
30


generate_full_name builds a name from values stored inside the function. add_two_numbers adds 10 + 20. Both print the result. They do not send a value back to the caller.

3. Function Returning a Value - Part 1

Functions return values with the return statement. If a function has no return, it returns None. Let us rewrite the functions above using return. From now on we get a value when we call the function, and we print that value.
example.py
def generate_full_name():
    first_name = 'Priya'
    last_name = 'Rao'
    space = ' '
    full_name = first_name + space + last_name
    return full_name

print(generate_full_name())

def add_two_numbers():
    num_one = 10
    num_two = 20
    total = num_one + num_two
    return total

print(add_two_numbers())


View:
output.txt
Priya Rao
30


The output looks the same, but now print is outside the function. You can store the returned value in a variable: name = generate_full_name().

4. Function with Parameters

In a function we can pass different data types (number, string, boolean, list, tuple, dictionary, or set) as parameters.


Single parameter: if the function takes a parameter, call it with an argument.

example.py
# syntax
# Declaring a function
def function_name(parameter):
    codes
    codes
# Calling function
print(function_name(argument))


Example:
example.py
def greetings(name):
    message = name + ', welcome to Python for Everyone!'
    return message

print(greetings('Priya'))

def add_ten(num):
    ten = 10
    return num + ten

print(add_ten(40))

def square_number(x):
    return x * x

print(square_number(10))

def area_of_circle(r):
    PI = 3.14
    area = PI * r ** 2
    return area

print(area_of_circle(10))

def sum_of_numbers(n):
    total = 0
    for i in range(n + 1):
        total += i
    return total

print(sum_of_numbers(10))   # 55
print(sum_of_numbers(100))  # 5050


View:
output.txt
Priya, welcome to Python for Everyone!
50
100
314.0
55
5050




add_ten(40) is 40 + 10 → 50



square_number(10) is 10 * 10 → 100



area_of_circle(10) is 3.14 * 10 ** 2 → 314.0



sum_of_numbers(10) adds 0 through 10 → 55



sum_of_numbers(100) adds 0 through 100 → 5050



Two parameters: a function may have two or more parameters. Call it with the same number of arguments.


example.py
# syntax
# Declaring a function
def function_name(para1, para2):
    codes
    codes
# Calling function
print(function_name(arg1, arg2))


Example:
example.py
def generate_full_name(first_name, last_name):
    space = ' '
    full_name = first_name + space + last_name
    return full_name

print('Full Name: ', generate_full_name('Priya', 'Rao'))

def sum_two_numbers(num_one, num_two):
    sum = num_one + num_two
    return sum

print('Sum of two numbers: ', sum_two_numbers(10, 20))

def calculate_age(current_year, birth_year):
    age = current_year - birth_year
    return age

print('Age: ', calculate_age(2026, 2004))

def weight_of_object(mass, gravity):
    weight = str(mass * gravity) + ' N'  # the value has to be changed to a string first
    return weight

print('Weight of an object in Newtons: ', weight_of_object(100, 9.81))


View:
output.txt
Full Name:  Priya Rao
Sum of two numbers:  30
Age:  22
Weight of an object in Newtons:  981.0 N


2026 - 2004 is 22. 100 * 9.81 is 981.0; str(...) lets us add the ' N' unit.

5. Passing Arguments with Key and Value

If you pass arguments with key and value (keyword arguments), the order does not matter.
example.py
# syntax
# Declaring a function
def function_name(para1, para2):
    codes
    codes
# Calling function
print(function_name(para1='John', para2='Doe'))  # the order of arguments does not matter here


Example:
example.py
def print_fullname(firstname, lastname):
    space = ' '
    full_name = firstname + space + lastname
    print(full_name)

print_fullname(firstname='Priya', lastname='Rao')

def add_two_numbers(num1, num2):
    total = num1 + num2
    return total

print(add_two_numbers(num2=20, num1=10))  # order does not matter


View:
output.txt
Priya Rao
30


num2=20 is written first, num1=10 second. Python still adds 10 + 20 because the names match the parameters.

6. Function Returning a Value - Part 2

If we do not return a value, the function returns None by default. To return a value we use return followed by the value. We can return any data type.


Returning a string:

example.py
def print_name(firstname):
    return firstname

print(print_name('Priya'))

def print_full_name(firstname, lastname):
    space = ' '
    full_name = firstname + space + lastname
    return full_name

print(print_full_name(firstname='Priya', lastname='Rao'))


View:
output.txt
Priya
Priya Rao



Returning a number:

example.py
def add_two_numbers(num1, num2):
    total = num1 + num2
    return total

print(add_two_numbers(10, 20))

def calculate_age(current_year, birth_year):
    age = current_year - birth_year
    return age

print('Age: ', calculate_age(2026, 2004))


View:
output.txt
30
Age:  22



Returning a boolean:

example.py
def is_even(n):
    if n % 2 == 0:
        return True    # return stops further execution of the function, similar to break
    return False

print(is_even(10))  # True
print(is_even(7))   # False


View:
output.txt
True
False


10 % 2 == 0, so the function returns True immediately. 7 is not even, so it falls through to return False.


Returning a list:

example.py
def find_even_numbers(n):
    evens = []
    for i in range(n + 1):
        if i % 2 == 0:
            evens.append(i)
    return evens

print(find_even_numbers(10))


View:
output.txt
[0, 2, 4, 6, 8, 10]


The loop walks 0 through 10 and keeps the even numbers in a list, then returns that list.

7. Function with Default Parameters

Sometimes we give parameters default values. If we do not pass those arguments when calling the function, the defaults are used.
example.py
# syntax
# Declaring a function
def function_name(param=value):
    codes
    codes
# Calling function
function_name()
function_name(arg)


Example:
example.py
def greetings(name='Priya'):
    message = name + ', welcome to Python for Everyone!'
    return message

print(greetings())
print(greetings('Rao'))

def generate_full_name(first_name='Priya', last_name='Rao'):
    space = ' '
    full_name = first_name + space + last_name
    return full_name

print(generate_full_name())
print(generate_full_name('David', 'Smith'))

def calculate_age(birth_year, current_year=2026):
    age = current_year - birth_year
    return age

print('Age: ', calculate_age(2004))

def weight_of_object(mass, gravity=9.81):
    weight = str(mass * gravity) + ' N'  # the value has to be changed to a string first
    return weight

print('Weight of an object in Newtons: ', weight_of_object(100))        # 9.81 - average gravity on Earth's surface
print('Weight of an object in Newtons: ', weight_of_object(100, 1.62))  # gravity on the surface of the Moon


View:
output.txt
Priya, welcome to Python for Everyone!
Rao, welcome to Python for Everyone!
Priya Rao
David Smith
Age:  22
Weight of an object in Newtons:  981.0 N
Weight of an object in Newtons:  162.0 N


greetings() uses the default name Priya. greetings('Rao') replaces it. calculate_age(2004) uses the default year 2026, so the age is 22. weight_of_object(100) uses Earth gravity 9.81. The second call passes Moon gravity 1.62 and gets 162.0 N.

8. Arbitrary Number of Arguments

If we do not know how many arguments we will pass, we can take an arbitrary number by adding * before the parameter name. Inside the function that parameter is a tuple.
example.py
# syntax
# Declaring a function
def function_name(*args):
    codes
    codes
# Calling function
function_name(param1, param2, param3, ...)


Example:
example.py
def sum_all_nums(*nums):
    total = 0
    for num in nums:
        total += num     # same as total = total + num
    return total

print(sum_all_nums(10, 20, 20))  # 50
print(sum_all_nums(10, 20, 30))  # 60


View:
output.txt
50
60


*nums collects every extra number. 10 + 20 + 20 = 50. 10 + 20 + 30 = 60.

9. Default and Arbitrary Number of Parameters in Functions

You can mix a normal (or default) parameter with *args. The named parameter comes first.
example.py
def generate_groups(team, *args):
    print(team)
    for i in args:
        print(i)

generate_groups('Team-1', 'Priya', 'Rao', 'David', 'Eyob')


View:
output.txt
Team-1
Priya
Rao
David
Eyob


team is 'Team-1'. The rest of the names land in args and print one per line.

10. Dictionary unpacking

You can call a function that has named parameters by unpacking a dictionary whose keys match the parameter names. You do that with **.
example.py
def greet(name, location):
    print("Hi there", name, "how is the weather in", location)

greet(name="Priya", location="Hyderabad")

my_dict = {"name": "Priya", "location": "Hyderabad"}
greet(**my_dict)


View:
output.txt
Hi there Priya how is the weather in Hyderabad
Hi there Priya how is the weather in Hyderabad


The first call uses keyword arguments. The second call unpacks the dictionary: name and location become the same keyword arguments.

11. Arbitrary Number of Named Arguments

You can also define a function that accepts an arbitrary number of named arguments. Inside the function they arrive as a dictionary.
example.py
def arbitrary_named_args(**args):
    print("I received an arbitrary number of arguments, totaling", len(args))
    print("They are provided as a dictionary in my function:", type(args))
    print("Let's print them:")
    for k, v in args.items():
        print(" * key:", k, "value:", v)

arbitrary_named_args(name="Priya", city="Hyderabad", score=20)


View:
output.txt
I received an arbitrary number of arguments, totaling 3
They are provided as a dictionary in my function: <class 'dict'>
Let's print them:
 * key: name value: Priya
 * key: city value: Hyderabad
 * key: score value: 20


Generally avoid **args unless you need it. It makes it harder to see what the function accepts.

12. Function as a Parameter of Another Function

You can pass functions around as parameters.
example.py
def square_number(n):
    return n ** n

def do_something(f, x):
    return f(x)

print(do_something(square_number, 3))  # 27


View:
output.txt
27


do_something receives the function square_number and the value 3. It calls f(x), which is square_number(3). The body is n ** n, so 3 ** 3 is 27 (this is not the same as n * n).
