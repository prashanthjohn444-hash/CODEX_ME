
Building API

Today we cover a RESTful API that uses HTTP methods to GET, PUT, POST, and DELETE data.

A RESTful API is an application program interface that uses those four HTTP requests. Days 26–27 gave you Flask and MongoDB. We use both here. Every CRUD app (Create, Read, Update, Delete) has endpoints that write to and read from a database.

A browser can send GET (and a form can send POST). To send PUT and DELETE you need a client. Postman is the usual choice. Insomnia is an alternative. Download one of them before you run this lesson.

Example public APIs:


Countries: https://restcountries.com/v3.1/all (the old restcountries.eu host is gone)

Cat breeds: https://api.thecatapi.com/v1/breeds

Structure of an API

An API endpoint is a URL that retrieves, creates, updates, or deletes a resource.

Example:
output.txt
https://api.twitter.com/1.1/lists/members.json


That URL returns the members of a list. Private members appear only if the authenticated user owns the list.

Typical shape: company host / version / purpose.

HTTP methods for object manipulation:
output.txt
GET        Used for object retrieval
POST       Used for object creation and object actions
PUT        Used for object update
DELETE     Used for object deletion

Retrieving data using get

json.dumps plus Flask Response returns JSON with the right MIME type.

1. Return dummy JSON
example.py
from flask import Flask, Response
import json
import os

app = Flask(__name__)


@app.route('/api/v1.0/students', methods=['GET'])
def students():
    student_list = [
        {
            'name': 'Priya',
            'country': 'Finland',
            'city': 'Helsinki',
            'skills': ['HTML', 'CSS', 'JavaScript', 'Python'],
        },
        {
            'name': 'David',
            'country': 'UK',
            'city': 'London',
            'skills': ['Python', 'MongoDB'],
        },
        {
            'name': 'John',
            'country': 'Sweden',
            'city': 'Stockholm',
            'skills': ['Java', 'C#'],
        },
    ]
    return Response(json.dumps(student_list), mimetype='application/json')


if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=True, host='0.0.0.0', port=port)

Getting a document by id

One student: http://localhost:5000/api/v1.0/students/5df68a21f106fe2d315bbc8b

<id> in the route is a path parameter.

from bson.objectid import ObjectId
from bson.json_util import dumps


@app.route('/api/v1.0/students/<id>', methods=['GET'])
def single_student(id):
    student = db.students.find({'_id': ObjectId(id)})
    return Response(dumps(student), mimetype='application/json')

Creating data using POST

POST creates a document. In Postman:


Method POST.

URL http://localhost:5000/api/v1.0/students.

Body → x-www-form-urlencoded (matches request.form).

Keys: name, country, city, skills, bio, birthyear.

Example values: Priya, Finland, Helsinki, HTML, CSS, Python, Likes teaching Python, 1990.

Send.

example.py
from flask import Flask, Response, request
from datetime import datetime
from bson.json_util import dumps


@app.route('/api/v1.0/students', methods=['POST'])
def create_student():
    name = request.form['name']
    country = request.form['country']
    city = request.form['city']
    skills = request.form['skills'].split(', ')
    bio = request.form['bio']
    birthyear = request.form['birthyear']
    created_at = datetime.now()
    student = {
        'name': name,
        'country': country,
        'city': city,
        'birthyear': birthyear,
        'skills': skills,
        'bio': bio,
        'created_at': created_at,
    }
    db.students.insert_one(student)
    return Response(
        dumps({'result': 'a new student has been created'}),
        mimetype='application/json',
    )


skills arrives as one string. .split(', ') turns "HTML, CSS, Python" into ['HTML', 'CSS', 'Python'].

Request
output.txt
POST /api/v1.0/students HTTP/1.1
Host: localhost:5000
Content-Type: application/x-www-form-urlencoded

name=Priya&country=Finland&city=Helsinki&skills=HTML%2C+CSS%2C+Python&bio=Likes+teaching+Python&birthyear=1990


View
output.txt
HTTP/1.1 200 OK
Content-Type: application/json

{"result": "a new student has been created"}


Then GET /api/v1.0/students again. The new document is in the list with a fresh _id and created_at.

You can put GET and POST on the same path because the method differs. Flask matches both the URL and methods=.

Updating using PUT

PUT replaces the student at /api/v1.0/students/<id>.

In Postman:


Method PUT.

URL http://localhost:5000/api/v1.0/students/5df68a21f106fe2d315bbc8b.

Same form fields as POST.

Send.

example.py
@app.route('/api/v1.0/students/<id>', methods=['PUT'])
def update_student(id):
    query = {'_id': ObjectId(id)}
    name = request.form['name']
    country = request.form['country']
    city = request.form['city']
    skills = request.form['skills'].split(', ')
    bio = request.form['bio']
    birthyear = request.form['birthyear']
    created_at = datetime.now()
    student = {
        'name': name,
        'country': country,
        'city': city,
        'birthyear': birthyear,
        'skills': skills,
        'bio': bio,
        'created_at': created_at,
    }
    db.students.update_one(query, {'$set': student})
    return Response(
        dumps({'result': 'student has been updated'}),
        mimetype='application/json',
    )


The original listing called update_one(query, student) without $set. PyMongo needs an update operator. Use {'$set': student} so only those fields change.

Request
output.txt
PUT /api/v1.0/students/5df68a21f106fe2d315bbc8b HTTP/1.1
Host: localhost:5000
Content-Type: application/x-www-form-urlencoded

name=Priya&country=Finland&city=Helsinki&skills=Python%2C+MongoDB&bio=Updated+bio&birthyear=1990


View
output.txt
{"result": "student has been updated"}


GET that id again. skills should now be ["Python", "MongoDB"].

Full app.py

All four methods in one file. Import request. Use dumps for every MongoDB value.
example.py
from flask import Flask, Response, request
from bson.objectid import ObjectId
from bson.json_util import dumps
from datetime import datetime
import pymongo
import os

app = Flask(__name__)

MONGODB_URI = 'mongodb+srv://priya:your_password@30daysofpython-twxkr.mongodb.net/test?retryWrites=true&w=majority'
client = pymongo.MongoClient(MONGODB_URI)
db = client['thirty_days_of_python']


@app.route('/api/v1.0/students', methods=['GET'])
def students():
    student_list = list(db.students.find())
    return Response(dumps(student_list), mimetype='application/json')


@app.route('/api/v1.0/students/<id>', methods=['GET'])
def single_student(id):
    student = db.students.find({'_id': ObjectId(id)})
    return Response(dumps(student), mimetype='application/json')


@app.route('/api/v1.0/students', methods=['POST'])
def create_student():
    student = {
        'name': request.form['name'],
        'country': request.form['country'],
        'city': request.form['city'],
        'birthyear': request.form['birthyear'],
        'skills': request.form['skills'].split(', '),
        'bio': request.form['bio'],
        'created_at': datetime.now(),
    }
    db.students.insert_one(student)
    return Response(
        dumps({'result': 'a new student has been created'}),
        mimetype='application/json',
    )


@app.route('/api/v1.0/students/<id>', methods=['PUT'])
def update_student(id):
    student = {
        'name': request.form['name'],
        'country': request.form['country'],
        'city': request.form['city'],
        'birthyear': request.form['birthyear'],
        'skills': request.form['skills'].split(', '),
        'bio': request.form['bio'],
        'created_at': datetime.now(),
    }
    db.students.update_one({'_id': ObjectId(id)}, {'$set': student})
    return Response(
        dumps({'result': 'student has been updated'}),
        mimetype='application/json',
    )


@app.route('/api/v1.0/students/<id>', methods=['DELETE'])
def delete_student(id):
    db.students.delete_one({'_id': ObjectId(id)})
    return Response(
        dumps({'result': 'student has been deleted'}),
        mimetype='application/json',
    )


if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=True, host='0.0.0.0', port=port)
