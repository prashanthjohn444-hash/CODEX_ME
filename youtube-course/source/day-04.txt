
Strings

Text is a string data type. Any data type written as text is a string. Any data under single, double or triple quote are strings. There are different string methods and built-in functions to deal with string data types. To check the length of a string use the len() function.

Creating a String
example.py
letter = 'P'                # A string could be a single character or a bunch of texts
print(letter)
print(len(letter))
greeting = 'Hello, World!'  # String could be made using a single or double quote, "Hello, World!"
print(greeting)
print(len(greeting))
sentence = "I hope you are enjoying 30 days of Python Challenge"
print(sentence)


View:
output.txt
P
1
Hello, World!
13
I hope you are enjoying 30 days of Python Challenge


Multiline string is created by using triple single (''') or triple double quotes ("""). See the example below.
example.py
multiline_string = '''I am a teacher and enjoy teaching.
I didn't find anything as rewarding as empowering people.
That is why I created 30 days of python.'''
print(multiline_string)

# Another way of doing the same thing
multiline_string = """I am a teacher and enjoy teaching.
I didn't find anything as rewarding as empowering people.
That is why I created 30 days of python."""
print(multiline_string)


View:
output.txt
I am a teacher and enjoy teaching.
I didn't find anything as rewarding as empowering people.
That is why I created 30 days of python.
I am a teacher and enjoy teaching.
I didn't find anything as rewarding as empowering people.
That is why I created 30 days of python.


String Concatenation

We can connect strings together. Merging or connecting strings is called concatenation. See the example below:
example.py
first_name = 'Priya'
last_name = 'Rao'
space = ' '
full_name = first_name + space + last_name
print(full_name)
print(len(first_name))
print(len(last_name))
print(len(first_name) > len(last_name))
print(len(full_name))


View:
output.txt
Priya Rao
5
3
True
9


Priya has 5 characters, Rao has 3, and Priya Rao has 9 (the space counts).

Escape Sequences in Strings

In Python and other programming languages \ followed by a character is an escape sequence. Let us see the most common escape characters:


\n: new line

\t: Tab means (8 spaces)

\\: Back slash

\': Single quote (')

\": Double quote (")


Now, let us see the use of the above escape sequences with examples.
example.py
print('I hope everyone is enjoying the Python Challenge.\nAre you ?')
print('Days\tTopics\tExercises')
print('Day 1\t5\t5')
print('Day 2\t6\t20')
print('Day 3\t5\t23')
print('Day 4\t1\t35')
print('This is a backslash  symbol (\\)')
print('In every programming language it starts with \"Hello, World!\"')


View:
output.txt
I hope everyone is enjoying the Python Challenge.
Are you ?
Days	Topics	Exercises
Day 1	5	5
Day 2	6	20
Day 3	5	23
Day 4	1	35
This is a backslash  symbol (\)
In every programming language it starts with "Hello, World!"


The gap between the tab columns depends on your terminal. \t jumps to the next tab stop.

String formatting

Old Style String Formatting (% Operator)

In Python there are many ways of formatting strings. In this section, we will cover some of them.
The % operator is used to format a set of variables enclosed in a tuple (a fixed size list), together with a format string, which contains normal text together with argument specifiers, special symbols like %s, %d, %f, %.number of digits f.


%s - String (or any object with a string representation, like numbers)

%d - Integers

%f - Floating point numbers

%.number of digits f - Floating point numbers with fixed precision

example.py
# Strings only
first_name = 'Priya'
last_name = 'Rao'
language = 'Python'
formated_string = 'I am %s %s. I teach %s' % (first_name, last_name, language)
print(formated_string)

# Strings and numbers
radius = 10
pi = 3.14
area = pi * radius ** 2
formated_string = 'The area of circle with a radius %d is %.2f.' % (radius, area)
print(formated_string)

python_libraries = ['Django', 'Flask', 'NumPy', 'Matplotlib', 'Pandas']
formated_string = 'The following are python libraries:%s' % (python_libraries)
print(formated_string)


View:
output.txt
I am Priya Rao. I teach Python
The area of circle with a radius 10 is 314.00.
The following are python libraries:['Django', 'Flask', 'NumPy', 'Matplotlib', 'Pandas']


%d is the whole number 10. %.2f keeps two digits after the point (314.00).

New Style String Formatting (str.format)

This format was introduced in Python version 3.
example.py
first_name = 'Priya'
last_name = 'Rao'
language = 'Python'
formated_string = 'I am {} {}. I teach {}'.format(first_name, last_name, language)
print(formated_string)

a = 50
b = 20

print('{} + {} = {}'.format(a, b, a + b))
print('{} - {} = {}'.format(a, b, a - b))
print('{} * {} = {}'.format(a, b, a * b))
print('{} / {} = {:.2f}'.format(a, b, a / b))
print('{} % {} = {}'.format(a, b, a % b))
print('{} // {} = {}'.format(a, b, a // b))
print('{} ** 2 = {}'.format(a, a ** 2))

radius = 10
pi = 3.14
area = pi * radius ** 2
formated_string = 'The area of a circle with a radius {} is {:.2f}.'.format(radius, area)
print(formated_string)


View:
output.txt
I am Priya Rao. I teach Python
50 + 20 = 70
50 - 20 = 30
50 * 20 = 1000
50 / 20 = 2.50
50 % 20 = 10
50 // 20 = 2
50 ** 2 = 2500
The area of a circle with a radius 10 is 314.00.


{:.2f} is the new-style match for %.2f. a ** 2 is used so the power stays a structured number (2500).

String Interpolation / f-Strings (Python 3.6+)

Another new string formatting is string interpolation, f-strings. Strings start with f and we can inject the data in their corresponding positions.
example.py
a = 50
b = 20
print(f'{a} + {b} = {a + b}')
print(f'{a} - {b} = {a - b}')
print(f'{a} * {b} = {a * b}')
print(f'{a} / {b} = {a / b:.2f}')
print(f'{a} % {b} = {a % b}')
print(f'{a} // {b} = {a // b}')
print(f'{a} ** 2 = {a ** 2}')


View:
output.txt
50 + 20 = 70
50 - 20 = 30
50 * 20 = 1000
50 / 20 = 2.50
50 % 20 = 10
50 // 20 = 2
50 ** 2 = 2500


Python Strings as Sequences of Characters

Python strings are sequences of characters, and share their basic methods of access with other Python ordered sequences of objects — lists and tuples. The simplest way of extracting single characters from strings (and individual members from any sequence) is to unpack them into corresponding variables.

Unpacking Characters
example.py
language = 'Python'
a, b, c, d, e, f = language
print(a)
print(b)
print(c)
print(d)
print(e)
print(f)


View:
output.txt
P
y
t
h
o
n


The number of names on the left must match the number of characters.

Accessing Characters in Strings by Index

In programming counting starts from zero. Therefore the first letter of a string is at zero index and the last letter of a string is the length of a string minus one.

Index positions for 'Python':




  Character
  P
  y
  t
  h
  o
  n





  Index
  0
  1
  2
  3
  4

example.py
language = 'Python'
first_letter = language[0]
print(first_letter)
second_letter = language[1]
print(second_letter)
last_index = len(language) - 1
last_letter = language[last_index]
print(last_letter)


View:
output.txt
P
y
n


If we want to start from the right end we can use negative indexing. -1 is the last index.

  Negative index

  -5

example.py

print(last_letter)
second_last = language[-2]
print(second_last)


View:
output.txt
n

Slicing Python Strings

In python we can slice strings into substrings.
example.py
language = 'Python'
first_three = language[0:3]  # starts at zero index and up to 3 but does not include 3
print(first_three)
last_three = language[3:6]
print(last_three)
last_three = language[-3:]
print(last_three)
last_three = language[3:]
print(last_three)


View:
output.txt
Pyt
hon
hon
hon


The end index is not included. language[0:3] is indexes 0, 1, 2.

Reversing a String

We can easily reverse strings in python.
example.py
greeting = 'Hello, World!'
print(greeting[::-1])


View:
output.txt
!dlroW ,olleH


Skipping Characters While Slicing

It is possible to skip characters while slicing by passing a step argument.
example.py
language = 'Python'
pto = language[0:6:2]
print(pto)


View:
output.txt
Pto


Start at 0, stop before 6, step 2: P (0), t (2), o (4).

The numbered walk-through below is every method from the original lesson, plus upper() and lower() (used in the exercises).

1. capitalize()

Converts the first character of the string to capital letter.
example.py
challenge = 'thirty days of python'
print(challenge.capitalize())


View:
output.txt
Thirty days of python


Only the first character changes. The other words stay lower.

2. count()

Returns occurrences of a substring in a string, count(substring, start=.., end=..). The start is a starting index for counting and end is the last index to count.
example.py
challenge = 'thirty days of python'
print(challenge.count('y'))
print(challenge.count('y', 7, 14))
print(challenge.count('th'))


View:
output.txt
3
1
2


'y' appears at indexes 5, 9, and 16. The slice 7:14 only keeps the one in days.

3. endswith()

Checks if a string ends with a specified ending.
example.py
challenge = 'thirty days of python'
print(challenge.endswith('on'))
print(challenge.endswith('tion'))


View:
output.txt
True
False


4. expandtabs()

Replaces tab character with spaces. Default tab size is 8. It takes a tab size argument.
example.py
challenge = 'thirty\tdays\tof\tpython'
print(challenge.expandtabs())
print(challenge.expandtabs(10))


View:
output.txt
thirty  days    of      python
thirty    days      of        python


5. find()

Returns the index of the first occurrence of a substring. If not found, returns -1.
example.py
challenge = 'thirty days of python'
print(challenge.find('y'))
print(challenge.find('th'))


View:
output.txt
5
0


6. rfind()

Returns the index of the last occurrence of a substring. If not found, returns -1.
example.py
challenge = 'thirty days of python'
print(challenge.rfind('y'))
print(challenge.rfind('th'))


View:
output.txt
16
17


find walks from the left. rfind walks from the right.

7. format()

Formats a string into a nicer output. More about string formatting: programiz format.
example.py
first_name = 'Priya'
last_name = 'Rao'
age = 22
job = 'teacher'
country = 'India'
sentence = 'I am {} {}. I am a {}. I am {} years old. I live in {}.'.format(
    first_name, last_name, job, age, country)
print(sentence)

radius = 10
pi = 3.14
area = pi * radius ** 2
result = 'The area of a circle with radius {} is {}'.format(str(radius), str(area))
print(result)


View:
output.txt
I am Priya Rao. I am a teacher. I am 22 years old. I live in India.
The area of a circle with radius 10 is 314.0


8. index()

Returns the lowest index of a substring. Additional arguments indicate starting and ending index (default 0 and string length - 1). If the substring is not found it raises a ValueError.
example.py
challenge = 'thirty days of python'
sub_string = 'da'
print(challenge.index(sub_string))
print(challenge.find(sub_string, 9))


View:
output.txt
7
-1


index('da', 9) would raise ValueError because 'da' is only at index 7. The line above uses find so the companion script can run. Try challenge.index(sub_string, 9) yourself to see the error.

9. rindex()

Returns the highest index of a substring. Additional arguments indicate starting and ending index (default 0 and string length - 1).
example.py
challenge = 'thirty days of python'
sub_string = 'da'
print(challenge.rindex(sub_string))
print(challenge.rindex('on', 8))


View:
output.txt
7
19


rindex(sub_string, 9) would also raise ValueError. 'on' starting at index 8 is found at 19 (python).

10. isalnum()

challenge = 'thirty days of python 2019'

View:
output.txt
True
True
False
False


A space is not alphanumeric, so the last two are False.

11. isalpha()

Checks if all string elements are alphabet characters (a-z and A-Z).
example.py
challenge = 'thirty days of python'
print(challenge.isalpha())
challenge = 'ThirtyDaysPython'
print(challenge.isalpha())
num = '123'
print(num.isalpha())


View:
output.txt
False
True
False


Spaces are excluded, so 'thirty days of python' is False.

12. isdecimal()

Checks if all characters in a string are decimal (0-9).
example.py
challenge = 'thirty days of python'
print(challenge.isdecimal())
challenge = '123'
print(challenge.isdecimal())
challenge = '12 3'
print(challenge.isdecimal())
num = '10'
print(num.isdecimal())
num = '10.5'
print(num.isdecimal())


View:
output.txt
False
True
False
True
False


A space is not allowed. A decimal point is not allowed either, so '10.5' is False.

13. isdigit()

Checks if all characters in a string are numbers (0-9 and some other unicode characters for numbers).
example.py
challenge = 'Thirty'
print(challenge.isdigit())
challenge = '30'
print(challenge.isdigit())
challenge = '\u00B2'
print(challenge.isdigit())


View:
output.txt
False
True
True


'\u00B2' is the superscript two (²). isdigit() accepts it. isdecimal() does not.

14. isnumeric()

Checks if all characters in a string are numbers or number related (just like isdigit(), just accepts more symbols, like ½).

print(num.isnumeric())

num = '10.5'
print(num.isnumeric())
print('ten'.isnumeric())


View:
output.txt
True
True
False
False

Returns a concatenated string.

Removes all given characters starting from the beginning and end of the string. With no argument it removes whitespace.

View:
