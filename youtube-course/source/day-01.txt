What is Python?

Python is a high-level, general-purpose programming language. High-level means you write instructions that look close to English instead of talking to the computer in ones and zeros. General-purpose means the same language can build a website, analyze a spreadsheet, automate a boring office task, or train an AI model.

A few facts that help you place it:


Created by Guido van Rossum, a Dutch programmer.

First released on 20 February 1991.

Named after the British comedy series Monty Python's Flying Circus, not the snake.

Open source: anyone can use it, read it, and contribute to it for free.

Interpreted: Python runs your code line by line. You do not compile it into a separate program first.

Object-oriented: you can group data and behavior into objects (you will meet this idea later in the challenge).

Dynamically typed: you do not have to declare a variable's type before you use it.


Python's design goal is readability. Compare a simple print in Python with the same idea in a more verbose language: you write print('Hello, World!') and you are done. That short path from idea to working code is why beginners start here and why professionals stay here.

The version you will learn in this challenge is Python 3.

How Python is used

Think of Python as a toolkit, not a single job title. People use it to:


Write programs and scripts — from a five-line file that renames photos to a large application used by millions of people.

Build web applications and APIs — with frameworks such as Django, Flask, and FastAPI.

Work with data — clean tables, plot charts, run statistics, and prepare datasets.

Build AI and machine learning systems — train models, run predictions, and talk to large language models.

Control hardware and science experiments — from Raspberry Pi projects to lab instruments.

Teach programming — many universities and bootcamps start with Python because the syntax stays out of the way.

Python for Artificial Intelligence

Python is the most common language in AI and machine learning. That is not because it is the fastest language on the CPU. It is because the AI community built almost all of its shared tools in Python, and because the language is easy to experiment with.

Here is what "Python for AI" actually means in practice:


Data first. AI models learn from data. Python (with libraries such as NumPy and pandas) is how people load, clean, and explore that data.

Model training. Libraries such as scikit-learn, TensorFlow, and PyTorch let you train models for prediction, classification, computer vision, and language.

Deep learning and large language models. Modern AI — image generators, chatbots, speech systems — is usually trained and served with Python code.

Glue code. Researchers and engineers use Python to connect data, models, APIs, and user interfaces. A short Python script can call an AI API and print the answer.

Notebooks. Tools such as Jupyter let you mix explanation, code, and charts. That workflow is standard in AI work.


If your goal is AI, this 30-day challenge is still the right start. AI libraries sit on top of the same basics you learn here: variables, lists, loops, functions, files, and packages. Without those, the AI tools will feel like magic you cannot control.

Python Shell

Python is an interpreted scripting language, so it does not need to be compiled. It executes the code line by line. Python comes with a Python Shell (Python Interactive Shell). It is used to execute a single Python command and get the result.

The Python shell waits for code from you. When you enter a line, it interprets that line and shows the result on the next line.

1. Open the shell

Open your terminal or command prompt and write:
terminal
python


View:
output.txt
Python 3.7.5 (default, Nov  1 2019, 02:16:32)
[Clang 11.0.0 (clang-1100.0.33.8)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>>


The >>> prompt means the shell is waiting. Type Python next to >>> and press Enter.

2. First expression

This is the first script on the Python interactive shell:
example.py
10 + 20


View:
output.txt
>>> 10 + 20
30
>>>


You wrote your first Python script on the interactive shell.

3. Exit the shell

To close the shell, next to >>> write exit() and press Enter.
example.py
exit()


View:
output.txt
>>> 10 + 20
30
>>> exit()


After exit() you are back in the normal terminal. You now know how to open the Python interactive shell and how to leave it.

4. Syntax errors

Python gives you a result if it understands the script. If not, it returns an error. Make a deliberate mistake and see what Python returns.
example.py
10 + 20
10 x 20


View:
output.txt
>>> 10 + 20
30
>>> 10 x 20
  File "<stdin>", line 1
    10 x 20
       ^
SyntaxError: invalid syntax


Using x as multiplication is a syntax error. x is not a valid operator in Python. Use an asterisk (*) for multiplication. The error points at the character to fix.

The process of identifying and removing errors from a program is called debugging.

5. Debugging

Debug the line by putting * in place of x.
example.py
10 + 20
10 x 20
10 * 20


View:
output.txt
>>> 10 + 20
30
>>> 10 x 20
  File "<stdin>", line 1
    10 x 20
       ^
SyntaxError: invalid syntax
>>> 10 * 20
200


The bug is fixed. The code ran and we got the result we expected. As a programmer you will see this kind of error on a daily basis. It is good to know how to debug. To be good at debugging you should understand what kind of error you are facing. Some of the Python errors you may encounter are SyntaxError, IndexError, NameError, ModuleNotFoundError, KeyError, ImportError, AttributeError, TypeError, ValueError, ZeroDivisionError. We will see more about different Python error types in later sections.

Basic Python

Python Syntax

A Python script can be written in the Python interactive shell or in the code editor. A Python file has an extension .py.

Python Indentation

An indentation is a white space in a text. Indentation in many languages is used to increase code readability; however, Python uses indentation to create blocks of code. In other programming languages, curly brackets are used to create code blocks instead of indentation. One of the common bugs when writing Python code is incorrect indentation.

A line that starts with extra space before any block is an error.
example.py
    "Hello, World!"    # This will cause an indentation error
"Hello, World!"        # This will run without causing error


View:
output.txt
>>>     "Hello, World!"    # This will cause an indentation error
  File "<stdin>", line 1
    "Hello, World!"    # This will cause an indentation error
IndentationError: unexpected indent
>>> "Hello, World!"        # This will run without causing error
'Hello, World!'


Do not put spaces in front of a top-level line. You will use indentation on purpose later, inside if and loops.

Data types

In Python there are several types of data types. Let us get started with the most common ones. Different data types will be covered in detail in other sections. For the time being, let us just go through the different data types and get familiar with them. You do not have to have a clear understanding now.

Number


Integer: Integer (negative, zero and positive) numbers
Example:

Float: Decimal number
Example:

Structured examples: 10.0, 3.14, 9.81

Complex
Example:

String

A collection of one or more characters under a single or double quote. If a string is more than one sentence then we use a triple quote.

Example:
example.py
'Priya'
'India'
'Python'
'I love teaching'
'I hope you are enjoying the first day of 30DaysOfPython Challenge'


Booleans

A boolean data type is either a True or False value. T and F should be always uppercase.

Example:
example.py
True   # Is the light on? If it is on, then the value is True
False  # Is the light on? If it is off, then the value is False


List

Python list is an ordered collection which allows to store different data type items. A list is similar to an array in JavaScript.

Example:
example.py
[10, 20, 30, 40, 50]                 # all the same data types - a list of numbers
['Banana', 'Orange', 'Mango', 'Avocado']  # all the same data types - a list of strings (fruits)
['India', 'Finland', 'Sweden', 'Norway']  # all the same data types - a list of strings (countries)
['Banana', 10, False, 9.81]          # different data types - string, integer, boolean and float


Dictionary

A Python dictionary object is an unordered collection of data in a key value pair format.

Example:
example.py
{
    'first_name': 'Priya',
    'last_name': 'Rao',
    'country': 'India',
    'city': 'Hyderabad',
    'age': 22,
    'is_married': False,
    'skills': ['JS', 'React', 'Node', 'Python']
}


Tuple

A tuple is an ordered collection of different data types like list but tuples can not be modified once they are created. They are immutable.

Example:
example.py
('Priya', 'Rao', 'Brook', 'Abraham', 'Lidiya')  # Names

example.py
('Earth', 'Jupiter', 'Neptune', 'Mars', 'Venus', 'Saturn', 'Uranus', 'Mercury')  # planets


Set

A set is a collection of data types similar to list and tuple. Unlike list and tuple, set is not an ordered collection of items. Like in Mathematics, set in Python stores only unique items.

In later sections, we will go in detail about each and every Python data type.

Example:
example.py
{10, 20, 30, 40}
{3.14, 9.81, 2.7}  # order is not important in set
