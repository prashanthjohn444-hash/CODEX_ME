
Modules

A module is a file containing a set of codes or a set of functions which can be included to an application. A module could be a file containing a single variable, a function, or a big code base.

You already used built-in functions on Day 2. A module is how Python groups extra tools: your own .py file, or a built-in library such as math or os.

The four import forms you will type today:




  #
  Syntax
  What you get





  1
  import mymodule
  The whole file. Call names as mymodule.generate_full_name(...)



  2
  from mymodule import generate_full_name
  One name. Call it directly



  3
  from mymodule import generate_full_name, sum_two_nums
  Several names



  4
  from mymodule import generate_full_name as fullname
  A shorter local name




import and from are the keywords. as only renames.

What is a Module

A module is just a Python file. The file name (without .py) is the module name.

This day folder already has two files that work together:


mymodule.py — names you can import

main.py — a script that imports those names


Creating a Module

To create a module we write our codes in a Python script and we save it as a .py file. Create a file named mymodule.py inside your project folder. Let us write some code in this file.
example.py
# mymodule.py file
def generate_full_name(firstname, lastname):
    return firstname + ' ' + lastname


The working file in this folder also stores a number, a dictionary, and a second function, so the later from / as examples have something to import:
example.py
# mymodule.py file (full version used by main.py)
def generate_full_name(firstname, lastname):
    space = ' '
    fullname = firstname + space + lastname
    return fullname


def sum_two_nums(num1, num2):
    return num1 + num2


gravity = 9.81
person = {
    "firstname": "Priya",
    "age": 22,
    "country": "India",
    "city": "Hyderabad"
}


Create main.py in the same folder and import mymodule.

Importing a Module

To import the file we use the import keyword and the name of the file only (no .py).
example.py
# main.py file
import mymodule
print(mymodule.generate_full_name('Priya', 'Rao'))


View:
output.txt
Priya Rao


After import mymodule, every public name lives on mymodule. You write mymodule.generate_full_name, not generate_full_name alone.

Import Functions from a Module

We can have many functions in a file and we can import all the functions differently. from copies the names into this file.
example.py
# main.py file
from mymodule import generate_full_name, sum_two_nums, person, gravity
print(generate_full_name('Priya', 'Rao'))
print(sum_two_nums(10, 20))
mass = 10
weight = mass * gravity
print(weight)
print(person['firstname'])


View:
output.txt
Priya Rao
30
98.10000000000001
Priya


sum_two_nums(10, 20) is 30. 10 * 9.81 is 98.10000000000001 (float arithmetic, not a clean 98.1). The dictionary key 'firstname' is 'Priya'.

Import Functions from a Module and Renaming

During importing we can rename the name of the module (or of each imported name) with as.
example.py
# main.py file
from mymodule import generate_full_name as fullname, sum_two_nums as total, person as p, gravity as g
print(fullname('Priya', 'Rao'))
print(total(10, 20))
mass = 10
print(mass)
weight = mass * g
print(weight)
print(p)
print(p['firstname'])


View:
output.txt
Priya Rao
30
10
98.10000000000001
{'firstname': 'Priya', 'age': 22, 'country': 'India', 'city': 'Hyderabad'}
Priya


fullname is generate_full_name. total is sum_two_nums. p is person. g is gravity. This is the same script as main.py in this folder. Run it from this folder so Python finds mymodule.py next to it.

OS Module

Using Python os module it is possible to automatically perform many operating system tasks. The OS module in Python provides functions for creating, changing current working directory, and removing a directory (folder), fetching its contents, changing and identifying the current directory.
example.py
import os





  #
  Call
  What it does





  1
  os.mkdir(name)
  Create a directory



  2
  os.chdir(path)
  Change the current directory



  3
  os.getcwd()
  Get the current working directory



  4
  os.rmdir(name)
  Remove an empty directory




Do not run mkdir / rmdir on a folder you still need. The four calls below are the same syntax as the original lesson.

1. os.mkdir()
example.py
import os
os.mkdir('directory_name')


View:
output.txt
# a folder named directory_name is created in the current directory


2. os.chdir()
example.py
os.chdir('path')


View:
output.txt
# the current working directory is now path


Use a real folder path on your computer. '.' means this folder. '..' means the parent folder.

3. os.getcwd()
example.py
print(os.getcwd())


View (yours will differ):
output.txt
D:\TEST\python-30-day-course\module-02-logic-and-reuse\12_Day_Modules


4. os.rmdir()
example.py
os.rmdir('directory_name')


View:
output.txt
# the empty folder directory_name is removed


os.rmdir() only deletes an empty folder. Fetching names inside a folder is os.listdir(path).

Statistics Module

The statistics module provides functions for mathematical statistics of numeric data. The popular statistical functions which are defined in this module: mean, median, mode, stdev etc.

Structured scores used below: 10, 20, 20, 30, 40, 50, 20. The extra 20 values give a clear mode. from statistics import * brings every public name in.
example.py
from statistics import *  # importing all the statistics modules
scores = [10, 20, 20, 30, 40, 50, 20]
print(mean(scores))
print(median(scores))
print(mode(scores))
print(stdev(scores))


View:
output.txt
27.142857142857142
20
20
13.801311186847084


1. mean()

mean() is the average: sum divided by count. 190 / 7.
example.py
from statistics import mean
print(mean([10, 20, 20, 30, 40, 50, 20]))


View:
output.txt
27.142857142857142


2. median()

median() is the middle value after sorting. Sorted scores: [10, 20, 20, 20, 30, 40, 50]. The middle item is 20.
example.py
from statistics import median
print(median([10, 20, 20, 30, 40, 50, 20]))


View:
output.txt
20


3. mode()

mode() is the value that appears most often. 20 appears three times.
example.py
from statistics import mode
print(mode([10, 20, 20, 30, 40, 50, 20]))


View:
output.txt
20


4. stdev()

stdev() is the sample standard deviation — how spread out the numbers are.
example.py
from statistics import stdev
print(stdev([10, 20, 20, 30, 40, 50, 20]))


View:
output.txt
13.801311186847084


You can also write import statistics and then statistics.mean(scores).

Importing from math

If we want to import only a specific function from the module we import it as follows:
example.py
from math import pi
print(pi)


View:
output.txt
3.141592653589793


It is also possible to import multiple functions at once:
example.py
from math import pi, sqrt, pow, floor, ceil, log10
print(pi)
print(sqrt(2))
print(pow(2, 3))
print(floor(9.81))
print(ceil(9.81))
print(log10(100))


View:
output.txt
3.141592653589793
1.4142135623730951
8.0
9
10
2.0


After from math import log10, the name is log10, not math.log10. math.log10 only works if you also wrote import math.

But if we want to import all the functions in the math module we can use *.
example.py
from math import *
print(pi)
print(sqrt(2))
print(pow(2, 3))
print(floor(9.81))
print(ceil(9.81))
print(log10(100))


View:
output.txt
3.141592653589793
1.4142135623730951
8.0
9
10
2.0


from math import * fills this file with every public math name. It is handy in a short script. In a larger file prefer import math so you can see where sqrt came from.

When we import we can also rename the name of the function.
example.py
from math import pi as PI
print(PI)


View:
output.txt
3.141592653589793

Random Module

By now you are familiar with importing modules. Let us do one more import to get very familiar with it. Let us import random module which gives us a random number between 0 and 0.9999.... The random module has lots of functions but in this section we will only use random and randint.
example.py
from random import random, randint
print(random())
print(randint(10, 50))


View (sample — yours will differ):
output.txt
0.374821905132
30


1. random()

random() takes no arguments. It returns a float in the half-open range [0.0, 1.0).
example.py
from random import random
print(random())


View (sample):
output.txt
0.374821905132


2. randint()

randint(a, b) returns a random integer including both ends.
example.py
from random import randint
print(randint(10, 50))


View (sample):
output.txt
30


The integer can be 10 or 50 or anything between.
