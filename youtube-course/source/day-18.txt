
Regular expressions

A regular expression or RegEx is a special text string that helps to find patterns in data. A RegEx can be used to check if some pattern exists in a different data type. To use RegEx in Python first we should import the RegEx module which is called re.

The re Module

After importing the module we can use it to detect or find patterns.
example.py
import re


dir(re) lists the names on the module. The methods we use today are match, search, findall, sub, and split.
example.py
import re
print([name for name in dir(re) if name in ('match', 'search', 'findall', 'sub', 'split')])


View:
output.txt
['findall', 'match', 'search', 'split', 'sub']


Methods in the re Module

To find a pattern we use different re methods that search for a match in a string.




  #
  Method
  What it does
  Example
  View





  1
  re.match(pattern, string, flags=0)
  Search only at the start of the string. Returns a match object or None.
  re.match('I love', 'I love Python')
  match object, span (0, 6)



  2
  re.search(pattern, string, flags=0)
  Search anywhere in the string. Returns the first match object or None.
  re.search('first', txt)
  match object



  3
  re.findall(pattern, string, flags=0)
  Return a list of every match.
  re.findall('python', txt, re.I)
  ['Python', 'python']



  4
  re.sub(pattern, repl, string, count=0, flags=0)
  Replace one or many matches.
  re.sub('%', '', noisy)
  cleaned text



  5
  re.split(pattern, string, maxsplit=0, flags=0)
  Split the string at each match. Returns a list.
  re.split(r'\n', txt)
  list of lines




re.I (same as re.IGNORECASE) is the case-ignore flag. The original lesson writes it as the third argument: re.match(substring, string, re.I).

A match object has these methods. Do not skip them.

1. re.match()
example.py
# syntax
re.match(substring, string, re.I)
# substring is a string or a pattern, string is the text we look for a pattern, re.I is case ignore

example.py
import re

txt = 'I love to teach python and javaScript'
# It returns an object with span, and match
match = re.match('I love to teach', txt, re.I)
print(match)
# We can get the starting and ending position of the match as tuple using span
span = match.span()
print(span)
# Lets find the start and stop position from the span
start, end = span
print(start, end)
substring = txt[start:end]
print(substring)


View:
output.txt
<re.Match object; span=(0, 15), match='I love to teach'>
(0, 15)
0 15
I love to teach


The pattern we are looking for is I love to teach. re.match() returns an object only if the text starts with the pattern.
example.py
import re

txt = 'I love to teach python and javaScript'
match = re.match('I like to teach', txt, re.I)
print(match)


View:
output.txt
None


The string does not start with I like to teach, therefore there was no match and the match method returned None.

Search is much better than match when the pattern is not at the start, because it can look for the pattern throughout the text. Search returns a match object with the first match that was found, otherwise it returns None. A much better re function is findall. This function checks for the pattern through the whole string and returns all the matches as a list.
example.py
import re

txt = 'Priya lives in Hyderabad. Priya teaches Python.'
print(re.search('Hyderabad', txt))
print(re.search('Hyderabad', txt).group())


View:
output.txt
<re.Match object; span=(15, 24), match='Hyderabad'>

The fourth positional argument of re.sub is count, not flags. re.I is the integer 2, so this call replaces at most two matches. Prefer the keyword form re.sub(pattern, repl, txt, flags=re.I) when you mean the ignore-case flag.

Let us add one more example. The following string is really hard to read unless we remove the % symbol. Replacing the % with an empty string will clean the text.

Writing RegEx Patterns

To declare a string variable we use a single or double quote. To declare a RegEx variable we use r'' (a raw string). The following pattern only identifies apple with lowercase. To make it case insensitive either we should rewrite our pattern or we should add a flag.
example.py
import re

regex_pattern = r'apple'
txt = 'Apple and banana are fruits. An old cliche says an apple a day a doctor way has been replaced by a banana a day keeps the doctor far far away. '
matches = re.findall(regex_pattern, txt)
print(matches)  # ['apple']

# To make case insensitive adding flag
matches = re.findall(regex_pattern, txt, re.I)
print(matches)  # ['Apple', 'apple']
# or we can use a set of characters method
regex_pattern = r'[Aa]pple'  # this mean the first letter could be Apple or apple
matches = re.findall(regex_pattern, txt)
print(matches)  # ['Apple', 'apple']


View:
output.txt
['apple']
['Apple', 'apple']
['Apple', 'apple']


Meta characters used when writing patterns:


[]: A set of characters

[a-c] means a or b or c

[a-z] means any letter from a to z

[A-Z] means any character from A to Z

[0-3] means 0 or 1 or 2 or 3

[0-9] means any number from 0 to 9

[A-Za-z0-9] any single character that is a to z, A to Z, or 0 to 9



\: uses to escape special characters

\d means: match where the string contains digits (numbers from 0-9)

\D means: match where the string does not contain digits



.: any character except new line character (\n)

^: starts with

r'^substring' e.g. r'^love', a sentence that starts with a word love

r'[^abc]' means not a, not b, not c



$: ends with

r'substring$' e.g. r'love$', a sentence that ends with a word love



*: zero or more times

r'[a]*' means a optional or it can occur many times



+: one or more times

r'[a]+' means at least once (or more)



?: zero or one time

r'[a]?' means zero times or once



{3}: Exactly 3 characters

{3,}: At least 3 characters

{3,8}: 3 to 8 characters

|: Either or

r'apple|banana' means either apple or a banana



(): Capture and group

Regular Expression Quantifiers

Default is greedy. Append ? for reluctant (non-greedy).




  Pattern
  Meaning
  Example
  View





  *
  0 or more
  re.findall(r'20*', '2 20 200')
  ['2', '20', '200']



  +
  1 or more
  re.findall(r'\d+', '10 20 30')
  ['10', '20', '30']



  ?
  0 or 1
  re.findall(r'e-?mail', 'email e-mail')
  ['email', 'e-mail']



  {2}
  Exactly 2
  re.findall(r'\d{2}', '10 20 30')
  ['10', '20', '30']



  {2, 5}
  Between 2 and 5
  re.findall(r'\d{2,5}', '1 10 100 1000')
  ['10', '100', '1000']



  {2,}
  2 or more
  re.findall(r'\d{2,}', '1 10 100')
  ['10', '100']

import re

Regular Expression Assertions




  Pattern
  Meaning
  Example
  View





  ^
  Start of string
  re.findall(r'^10', '10 20 30')
  ['10']



  $
  End of string
  re.findall(r'50$', '10 20 50')

  \b
  Word boundary
  re.findall(r'\b20\b', '120 20 201')

  Non-word boundary

  Positive lookahead
  re.findall(r'\d+(?=%)', '10% 20 pts')

Regular Expression Replacement

The cheat-sheet replacement tokens are the JavaScript / editor form. Python re.sub uses a different replacement language.




  Cheat-sheet token
  Meaning
  Python re.sub replacement





  $$
  Inserts $
  '\$' or '$$' is not special; write '$'



  $&
  Insert entire match
  \g<0>



  `$``
  Insert preceding string
  not built-in; use a function replacement



  $'
  Insert following string
  not built-in; use a function replacement



  $Y
  Insert Y'th captured group
  \1, \2, or \g<1>



example.py
import re

print(re.sub(r'(\d+)', r'[\g<0>]', '10 20 30'))
print(re.sub(r'(\d+), (\d+)', r'\2, \1', '10, 20'))


View:
output.txt
[10] [20] [30]
20, 10

Groups, lookaheads, and flags

These rows were on the cheat sheet. Here they are as runnable Python.
example.py
import re

text = 'Priya, 22, Hyderabad, scores 10 20 30 40 50'

# capturing group
m = re.search(r'(\w+), (\d+), (\w+)', text)
print(m.group())      # whole match
print(m.group(1))     # Priya
print(m.group(2))     # 22
print(m.group(3))     # Hyderabad

# backreference: same number twice
print(re.findall(r'(\d+) \1', '10 10 20 30 30'))

# positive lookahead: digits that sit before a comma
print(re.findall(r'\d+(?=,)', '10, 20, 30'))

# negative lookahead: the word score not followed by s
print(re.findall(r'score(?!s)', 'score scores'))

# flags: ignore case + multiline
print(re.findall(r'^priya', 'Priya\npriya', re.I | re.M))


View:
output.txt
Priya, 22, Hyderabad
Priya
22
Hyderabad
['10', '30']
['10', '20']
['score']
['Priya', 'priya']
