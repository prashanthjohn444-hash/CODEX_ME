
Python Web Scraping

What is Web Scraping

The internet is full of a huge amount of data which can be used for different purposes. To collect this data we need to know how to scrape data from a website.

Web scraping is the process of extracting and collecting data from websites and storing it on a local machine or in a database.

In this section, we will use the beautifulsoup and requests packages to scrape data. The package version we are using is Beautiful Soup 4.

To start scraping websites you need requests, beautifulsoup4, and a website.

To scrape data from websites, a basic understanding of HTML tags and CSS selectors is needed. We target content from a website using HTML tags, classes, and/or ids.

Fetch a page with requests

Let us declare a url variable for the website which we are going to scrape.

The original lesson uses the UCI Machine Learning Repository list. The same requests calls work on any public URL.
example.py
import requests
from bs4 import BeautifulSoup

url = 'https://archive.ics.uci.edu/ml/datasets.php'

# Lets use the requests get method to fetch the data from url
response = requests.get(url)

# lets check the status
status = response.status_code
print(status)  # 200 means the fetching was successful


View (when the server answers OK):
output.txt
200


200 means the fetching was successful. Other common codes: 404 (page not found), 403 (forbidden), 500 (server error).

1. requests.get()

requests.get(url) sends an HTTP GET request and returns a Response object.
example.py
response = requests.get(url)
print(type(response))


View:
output.txt
<class 'requests.models.Response'>


For the local demo you already have the HTML string, so you do not need get(). On a live site, always start with requests.get(url).

2. response.status_code

status_code is the HTTP status number.
example.py
status = response.status_code
print(status)


View:
output.txt
200


3. response.content

content is the raw page body as bytes. Pass this to Beautiful Soup.
example.py
content = response.content
print(type(content))


View:
output.txt
<class 'bytes'>


4. response.text

text is the same page decoded as a string. Useful when you want to print or search the HTML as text.
example.py
print(type(response.text))
print(response.text[:40])


View (first characters change by site):
output.txt
<class 'str'>
<!DOCTYPE html>

Parse HTML with Beautiful Soup

Using Beautiful Soup to parse content from the page:
example.py
import requests
from bs4 import BeautifulSoup

url = 'https://archive.ics.uci.edu/ml/datasets.php'

response = requests.get(url)
content = response.content  # we get all the content from the website
soup = BeautifulSoup(content, 'html.parser')  # beautiful soup will give a chance to parse
print(soup.title)            # <title>UCI Machine Learning Repository: Data Sets</title>
print(soup.title.get_text()) # UCI Machine Learning Repository: Data Sets
print(soup.body)             # gives the whole page on the website
print(response.status_code)


View (live UCI page — title text can change):
output.txt
<title>UCI Machine Learning Repository: Data Sets</title>
UCI Machine Learning Repository: Data Sets
<body>...</body>
200

5. BeautifulSoup()

BeautifulSoup(markup, parser) builds the parse tree.
example.py
soup = BeautifulSoup(html, 'html.parser')
print(type(soup))


View:
output.txt
<class 'bs4.BeautifulSoup'>


'html.parser' is built into Python. Other parsers: 'lxml' (faster, extra install), 'html5lib' (very patient with broken HTML).

6. soup.title

soup.title is the first <title> tag, not only the text.
example.py
print(soup.title)
print(type(soup.title))


View:
output.txt
<title>Score Board</title>
<class 'bs4.element.Tag'>


soup.body and soup.head work the same way: they return the tag, or None if it is missing.

7. get_text()

get_text() (also getText()) pulls the visible text out of a tag. .text is a shortcut for the same thing.
example.py
print(soup.title.get_text())
print(soup.title.text)
print(soup.find('h1').get_text())


View:
output.txt
Score Board
Score Board
Scores


8. soup.body

soup.body gives the whole <body> of the page.
example.py
print(soup.body.name)
print('h1' in str(soup.body))


View:
output.txt
body
True


Printing soup.body on a large site dumps the entire page. Use find() / find_all() instead of reading that dump by eye.

9. find()

find(name, attrs, ...) returns the first matching tag, or None.
example.py
print(soup.find('h1'))
print(soup.find('h1', {'id': 'title'}))
print(soup.find('table', {'cellpadding': '3'}))
print(soup.find('footer'))


View:
output.txt
<h1 id="title">Scores</h1>
<h1 id="title">Scores</h1>
<table cellpadding="3">...</table>
None


You can select using id, class, or HTML tag. For more information check the Beautiful Soup documentation.

10. find_all()

find_all(name, attrs, ...) returns a list of every match. findAll() is the old name of the same method.
example.py
tables = soup.find_all('table', {'cellpadding': '3'})
print(type(tables))
print(len(tables))

tds = soup.find_all('td')
print([td.get_text() for td in tds])


View:
output.txt
<class 'bs4.element.ResultSet'>
1
['Name', 'Score', 'Priya', '10', 'Arjun', '20', 'Maya', '30', 'Leila', '40', 'Omar', '50']


The result is a list. Take one item with tables[0].

11. select() and select_one()

select(css) returns every tag that matches a CSS selector. select_one(css) returns the first match only.
example.py
print(soup.select('tr.row'))
print(soup.select_one('a.link'))
print(soup.select('#title'))


View:
output.txt
[<tr class="row"><td>Priya</td><td>10</td></tr>, <tr class="row"><td>Arjun</td><td>20</td></tr>, ...]
<a class="link" href="/next">Next</a>
[<h1 id="title">Scores</h1>]


find / find_all use tag name and attributes. select / select_one use CSS: .class, #id, table td, a.link.

12. get() and attrs

tag.get('href') reads one attribute. tag.attrs is the whole attribute dictionary. tag.name is the tag name ('a', 'td', ...).
example.py
link = soup.select_one('a')
print(link.get('href'))
print(link.attrs)
print(link.name)
print(link.has_attr('href'))


View:
output.txt
/next
{'href': '/next', 'class': ['link']}
a
True

14. Other Beautiful Soup methods you should not skip

These methods are on every tag and on the soup itself. Day 22 keeps them. Try each line.

print(soup.find('td').find_parent('table').name) # table
print(soup.find('h1').find_next_sibling('table').name)  # table

rows = soup.find_all('tr', class_='row')

print(list(soup.stripped_strings))
# ['Score Board', 'Scores', 'Name', 'Score', 'Priya', '10', ...]

# walk / replace (do this on a copy if you still need the original tree)

Scrape a table

We are targeting the table with a cellpadding attribute of 3. The result of find_all is a list; we take the first table, then walk its first row.
example.py
import requests
from bs4 import BeautifulSoup

url = 'https://archive.ics.uci.edu/ml/datasets.php'
response = requests.get(url)
content = response.content
soup = BeautifulSoup(content, 'html.parser')

tables = soup.find_all('table', {'cellpadding': '3'})
# We are targeting the table with cellpadding attribute with the value of 3
# We can select using id, class or HTML tag
table = tables[0]  # the result is a list, we are taking out data from it
for td in table.find('tr').find_all('td'):
    print(td.text)


If you run this code on the live UCI page, you can see that the extraction is half done. You can continue doing it because it is part of exercise 1 (Level 2).

Same walk on the local score table (this view is stable):
example.py
tables = soup.find_all('table', {'cellpadding': '3'})
table = tables[0]
for td in table.find('tr').find_all('td'):
    print(td.text)

Walk every data row and collect name / score pairs:
example.py
rows = []
for tr in table.find_all('tr')[1:]:
    cells = [td.get_text(strip=True) for td in tr.find_all('td')]
    rows.append({'name': cells[0], 'score': int(cells[1])})
print(rows)
print([row['score'] for row in rows])


View:
output.txt
[{'name': 'Priya', 'score': 10}, {'name': 'Arjun', 'score': 20}, {'name': 'Maya', 'score': 30}, {'name': 'Leila', 'score': 40}, {'name': 'Omar', 'score': 50}]
[10, 20, 30, 40, 50]


table.find('tr') is only the first row (the header). table.find_all('tr') is every row.
