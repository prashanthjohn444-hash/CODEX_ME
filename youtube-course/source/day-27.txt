
Python with MongoDB

Python is a backend language. It can talk to SQL databases and to NoSQL databases. Today we connect Python to MongoDB, which is NoSQL.

MongoDB

MongoDB stores data as JSON-like documents. That makes it flexible and easy to scale.

Connecting Flask application to MongoDB Cluster

Put the URI in a variable. Do not commit a real password.
example.py
from flask import Flask, render_template
import os
import pymongo

MONGODB_URI = 'mongodb+srv://priya:your_password_goes_here@30daysofpython-twxkr.mongodb.net/test?retryWrites=true&w=majority'
client = pymongo.MongoClient(MONGODB_URI)
print(client.list_database_names())

app = Flask(__name__)
if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=True, host='0.0.0.0', port=port)

Creating a database and collection

MongoDB creates a database and a collection the first time you write a document. We will use database thirty_days_of_python and collection students.

Two ways to get a database handle:
example.py
db = client.name_of_database          # attribute style
db = client['name_of_database']       # dictionary style


insert_one() writes one document.
example.py
from flask import Flask
import os
import pymongo

MONGODB_URI = 'mongodb+srv://priya:your_password_goes_here@30daysofpython-twxkr.mongodb.net/test?retryWrites=true&w=majority'
client = pymongo.MongoClient(MONGODB_URI)
db = client.thirty_days_of_python
db.students.insert_one({
    'name': 'Priya',
    'country': 'Finland',
    'city': 'Helsinki',
    'age': 250,
})
print(client.list_database_names())


View
output.txt
['thirty_days_of_python', 'admin', 'local']

Inserting many documents to collection

insert_one() is one document. For several documents use insert_many() or a loop of insert_one().
example.py
import pymongo

MONGODB_URI = 'mongodb+srv://priya:your_password_goes_here@30daysofpython-twxkr.mongodb.net/test?retryWrites=true&w=majority'
client = pymongo.MongoClient(MONGODB_URI)
db = client.thirty_days_of_python

students = [
    {'name': 'David', 'country': 'UK', 'city': 'London', 'age': 34},
    {'name': 'John', 'country': 'Sweden', 'city': 'Stockholm', 'age': 28},
    {'name': 'Sami', 'country': 'Finland', 'city': 'Helsinki', 'age': 25},
]
for student in students:
    db.students.insert_one(student)


Same result with one call:
example.py
db.students.insert_many(students)


After Priya plus these three, the collection has four documents.

MongoDB Find

find() and find_one() read documents. They are the NoSQL version of SQL SELECT.

The snippets below reuse this connection. Paste your URI once at the top of the file:
example.py
import pymongo
from bson.objectid import ObjectId

MONGODB_URI = 'mongodb+srv://priya:your_password_goes_here@30daysofpython-twxkr.mongodb.net/test?retryWrites=true&w=majority'
client = pymongo.MongoClient(MONGODB_URI)
db = client['thirty_days_of_python']

1. find_one()

No filter → first document in the collection.
example.py
student = db.students.find_one()
print(student)


View
output.txt
{'_id': ObjectId('5df68a21f106fe2d315bbc8b'), 'name': 'Priya', 'country': 'Finland', 'city': 'Helsinki', 'age': 250}


2. find_one by _id
example.py
student = db.students.find_one({'_id': ObjectId('5df68a23f106fe2d315bbc8c')})
print(student)


View
output.txt
{'_id': ObjectId('5df68a23f106fe2d315bbc8c'), 'name': 'David', 'country': 'UK', 'city': 'London', 'age': 34}


3. find()

No filter → every document. The return value is a pymongo.cursor.Cursor. Loop it.
example.py
students = db.students.find()
for student in students:
    print(student)


View
output.txt

{'_id': ObjectId('5df68a23f106fe2d315bbc8d'), 'name': 'John', 'country': 'Sweden', 'city': 'Stockholm', 'age': 28}
{'_id': ObjectId('5df68a23f106fe2d315bbc8e'), 'name': 'Sami', 'country': 'Finland', 'city': 'Helsinki', 'age': 25}


4. find with projection

Second argument picks fields. 1 = include, 0 = exclude. Do not mix 1 and 0 except for _id.
example.py
students = db.students.find({}, {'_id': 0, 'name': 1, 'country': 1})
for student in students:
    print(student)


View
output.txt
{'name': 'Priya', 'country': 'Finland'}
{'name': 'David', 'country': 'UK'}
{'name': 'John', 'country': 'Sweden'}
{'name': 'Sami', 'country': 'Finland'}

Update with query

1. update_one()

Takes a query and a new-value object. Priya's age 250 is not a real age. Set it to 38.
example.py
query = {'age': 250}
new_value = {'$set': {'age': 38}}
db.students.update_one(query, new_value)

for student in db.students.find():
    print(student)


View
output.txt
{'_id': ObjectId('5df68a21f106fe2d315bbc8b'), 'name': 'Priya', 'country': 'Finland', 'city': 'Helsinki', 'age': 38}
{'_id': ObjectId('5df68a23f106fe2d315bbc8c'), 'name': 'David', 'country': 'UK', 'city': 'London', 'age': 34}
{'_id': ObjectId('5df68a23f106fe2d315bbc8d'), 'name': 'John', 'country': 'Sweden', 'city': 'Stockholm', 'age': 28}
{'_id': ObjectId('5df68a23f106fe2d315bbc8e'), 'name': 'Sami', 'country': 'Finland', 'city': 'Helsinki', 'age': 25}


$set changes only the fields you name. Without $set, update_one would try to replace the whole document.

2. update_many()

Same two arguments, but every match is updated.
example.py
query = {'country': 'Finland'}
new_value = {'$set': {'city': 'Helsinki'}}
result = db.students.update_many(query, new_value)
print(result.modified_count)


Delete Document

1. delete_one()

Takes a query. Removes the first match only. Delete John.
example.py
query = {'name': 'John'}
db.students.delete_one(query)

for student in db.students.find():
    print(student)


View — John is gone:
output.txt
{'_id': ObjectId('5df68a21f106fe2d315bbc8b'), 'name': 'Priya', 'country': 'Finland', 'city': 'Helsinki', 'age': 38}
{'_id': ObjectId('5df68a23f106fe2d315bbc8c'), 'name': 'David', 'country': 'UK', 'city': 'London', 'age': 34}
{'_id': ObjectId('5df68a23f106fe2d315bbc8e'), 'name': 'Sami', 'country': 'Finland', 'city': 'Helsinki', 'age': 25}


2. delete_many()

Same query object. Deletes every match. An empty query deletes the whole collection:
example.py
db.students.delete_many({'country': 'Sweden'})
db.students.delete_many({})    # every document — irreversible


Drop a collection

drop() removes the collection itself, not just the documents.
example.py
db.students.drop()


thirty_days_of_python no longer lists students.

  #
  Method
  What it does





  1
  MongoClient(uri)
  Connect



  2
  list_database_names()
  Names of databases



  3
  client.db / client['db']
  Open or create a database



  4

  Insert one document



  5
  insert_many(list)
  Insert many documents



  6
  find_one(query)
  First match



  7
  find(query, projection)
  Cursor of matches



  8
  find(query)
  Filter (country, city, $gt, $lt, …)



  9
  limit(n)
  Cap the number of results



  10
  sort(field, direction)
  1 ascending, -1 descending



  11
  update_one(query, {'$set': ...})
  Update first match



  12
  update_many(query, {'$set': ...})
  Update every match



  13
  delete_one(query)
  Delete first match



  14
  delete_many(query)
  Delete every match



  15
  drop()
  Delete the collection
