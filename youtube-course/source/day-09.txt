
Conditionals

By default, statements in a Python script run from top to bottom. You can change that flow in two ways:


Conditional execution: a block runs only if an expression is true (if, elif, else — this day)

Repetitive execution: a block repeats while an expression is true (loops — Day 10)


Comparison and logical operators from Day 3 are the conditions you put after if. Remember the indentation after the colon. The indented block is the code that belongs to that condition.

The numbered constructs below use structured numbers (10, 20, 30, 40, 50) and the same person (Priya, Hyderabad) as earlier days.

1. if

In Python the keyword if checks whether a condition is true and then runs the indented block. The colon at the end of the if line is required.
example.py
# syntax
if condition:
    this part of code runs for truthy conditions


Example:
example.py
a = 30
if a > 0:
    print('A is a positive number')


View:
output.txt
A is a positive number


30 is greater than 0, so the condition is true and the block runs. If the condition is false, you see nothing. To handle the false case you need else.

2. if else

If the condition is true the first block runs. If it is not true, the else block runs.
example.py
# syntax
if condition:
    this part of code runs for truthy conditions
else:
    this part of code runs for false conditions


Example:
example.py
a = 30
if a < 0:
    print('A is a negative number')
else:
    print('A is a positive number')


View:
output.txt
A is a positive number


30 < 0 is false, so the else block runs. How about more than two cases? Use elif.

3. if elif else

In daily life we check more than one or two conditions. Programming is the same. Use elif (else if) when you have several tests. Python checks them from top to bottom and runs the first block whose condition is true.
example.py
# syntax
if condition:
    code
elif condition:
    code
else:
    code


Example:
example.py
a = 0
if a > 0:
    print('A is a positive number')
elif a < 0:
    print('A is a negative number')
else:
    print('A is zero')


View:
output.txt
A is zero


Same tests with other values:
example.py
a = 30
if a > 0:
    print('A is a positive number')
elif a < 0:
    print('A is a negative number')
else:
    print('A is zero')

a = -20
if a > 0:
    print('A is a positive number')
elif a < 0:
    print('A is a negative number')
else:
    print('A is zero')


View:
output.txt
A is a positive number
A is a negative number


30 takes the first branch. -20 fails a > 0, matches a < 0, and prints that it is negative. 0 matches neither, so else runs.

4. Short Hand

A one-line conditional. You still need both the if part and the else part.
example.py
# syntax
code if condition else code


Example:
example.py
a = 30
print('A is positive') if a > 0 else print('A is negative')


View:
output.txt
A is positive


The first condition is met, so A is positive is printed. This is the same idea as if / else, written on one line.

5. Nested Conditions

Conditions can sit inside other conditions.
example.py
# syntax
if condition:
    code
    if condition:
        code


Example:
example.py
a = 0
if a > 0:
    if a % 2 == 0:
        print('A is a positive and even integer')
    else:
        print('A is a positive number')
elif a == 0:
    print('A is zero')
else:
    print('A is a negative number')


View:
output.txt
A is zero


a is 0, so the outer if a > 0 is false. The elif a == 0 branch runs.

When a is a positive even number from the structured set, the inner if runs:
example.py
a = 20
if a > 0:
    if a % 2 == 0:
        print('A is a positive and even integer')
    else:
        print('A is a positive number')
elif a == 0:
    print('A is zero')
else:
    print('A is a negative number')


View:
output.txt
A is a positive and even integer


20 > 0 is true, then 20 % 2 == 0 is true, so Python prints that it is positive and even. You can avoid a nested if by using the logical operator and.

6. If Condition and Logical Operators

and means both tests must be true.
example.py
# syntax
if condition and condition:
    code


Example:
example.py
a = 0
if a > 0 and a % 2 == 0:
    print('A is an even and positive integer')
elif a > 0 and a % 2 != 0:
    print('A is a positive integer')
elif a == 0:
    print('A is zero')
else:
    print('A is negative')


View:
output.txt
A is zero


Same tests with 20:
example.py
a = 20
if a > 0 and a % 2 == 0:
    print('A is an even and positive integer')
elif a > 0 and a % 2 != 0:
    print('A is a positive integer')
elif a == 0:
    print('A is zero')
else:
    print('A is negative')


View:
output.txt
A is an even and positive integer


20 > 0 is true and 20 % 2 == 0 is true, so the first branch runs. This is the nested example flattened into one if with and.

7. If and Or Logical Operators

or means at least one of the tests must be true.
example.py
# syntax
if condition or condition:
    code


Example:
example.py
user = 'Priya'
access_level = 3
if user == 'admin' or access_level >= 4:
    print('Access granted!')
else:
    print('Access denied!')


View:
output.txt
Access denied!


user is not 'admin' and 3 >= 4 is false, so both sides of or fail and the else block runs.

Same test when one side is enough:
example.py
user = 'Priya'
access_level = 10
if user == 'admin' or access_level >= 4:
    print('Access granted!')
else:
    print('Access denied!')

user = 'admin'
access_level = 3
if user == 'admin' or access_level >= 4:
    print('Access granted!')
else:
    print('Access denied!')


View:
output.txt
Access granted!
Access granted!


access_level of 10 is >= 4, so the first call is granted even though the user is not 'admin'. The second call is granted because user == 'admin', even though the level is only 3.
