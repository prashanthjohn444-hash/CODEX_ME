
Python for Web

Python is a general-purpose language. It can run on the web. There are many Python web frameworks. Django and Flask are the most common. Today we use Flask.

Flask

Flask is a small web framework written in Python. It uses the Jinja2 template engine. You can also pair Flask with a front-end library such as React.

Use a virtual environment so this project's packages stay separate from the rest of your machine (Day 23).

Creating routes

A route is a URL path. Flask maps each path to a Python function with the @app.route(...) decorator.

1. Home route

/ is the home page.
example.py
from flask import Flask
import os

app = Flask(__name__)

@app.route('/')
def home():
    return '<h1>Welcome</h1>'

if __name__ == '__main__':
    # PORT comes from the host when you deploy; 5000 is the local default
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=True, host='0.0.0.0', port=port)

Request methods

The common HTTP methods map to CRUD:




  #
  Method
  CRUD
  What it does





  1
  GET
  Read
  Fetch a page or data. Do not change data.



  2
  POST
  Create
  Send a form or new record to the server.



  3
  PUT
  Update
  Replace a resource.



  4
  DELETE
  Delete
  Remove a resource.




The browser address bar only does GET. An HTML form can do GET or POST. request.method tells you which one arrived. request.form['content'] reads the textarea named content.

1. GET and POST on /post

Stop Flask from caching CSS while you edit styles. Add a result route. Accept both methods on /post.
example.py
from flask import Flask, render_template, request, redirect, url_for
import os

app = Flask(__name__)
app.config['SEND_FILE_MAX_AGE_DEFAULT'] = 0


@app.route('/')
def home():
    techs = ['HTML', 'CSS', 'Flask', 'Python']
    name = '30 Days Of Python Programming'
    return render_template('home.html', techs=techs, name=name, title='Home')


@app.route('/about')
def about():
    name = '30 Days Of Python Programming'
    return render_template('about.html', name=name, title='About Us')


@app.route('/result')
def result():
    return render_template('result.html')


@app.route('/post', methods=['GET', 'POST'])
def post():
    name = 'Text Analyzer'
    if request.method == 'GET':
        return render_template('post.html', name=name, title=name)
    if request.method == 'POST':
        content = request.form['content']
        print(content)
        return redirect(url_for('result'))


if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))
    app.run(debug=True, host='0.0.0.0', port=port)
