
Higher Order Functions

In Python functions are treated as first class citizens, allowing you to perform the following operations on functions:


A function can take one or more functions as parameters

A function can be returned as a result of another function

A function can be modified

A function can be assigned to a variable


In this section, we will cover:


Handling functions as parameters

Returning functions as return value from another functions

Using Python closures and decorators


A higher order function is a function that takes another function as an argument, or returns a function, or both. map, filter, reduce, and sorted (with key=) are the built-in ones you will type today. lambda is the short function you often pass into them.

Function as a Parameter
example.py
def sum_numbers(nums):  # normal function
    return sum(nums)    # uses the built-in sum function

def higher_order_function(f, lst):  # function as a parameter
    summation = f(lst)
    return summation

result = higher_order_function(sum_numbers, [10, 20, 30, 40, 50])
print(result)


View:
output.txt
150


higher_order_function does not add the numbers itself. It calls whatever function you pass in. Here that function is sum_numbers, so 10 + 20 + 30 + 40 + 50 is 150.

Function as a Return Value
example.py
def square(x):          # a square function
    return x ** 2

def cube(x):            # a cube function
    return x ** 3

def absolute(x):        # an absolute value function
    if x >= 0:
        return x
    else:
        return -(x)

def higher_order_function(kind):  # a higher order function returning a function
    if kind == 'square':
        return square
    elif kind == 'cube':
        return cube
    elif kind == 'absolute':
        return absolute

result = higher_order_function('square')
print(result(10))
result = higher_order_function('cube')
print(result(10))
result = higher_order_function('absolute')
print(result(-10))


View:
output.txt
100
1000
10


You can see from the above example that the higher order function is returning different functions depending on the passed parameter. 10 ** 2 is 100. 10 ** 3 is 1000. absolute(-10) is 10.

Python Closures

Python allows a nested function to access the outer scope of the enclosing function. This is known as a Closure. Let us have a look at how closures work in Python. In Python, closure is created by nesting a function inside another encapsulating function and then returning the inner function. See the example below.

Example:
example.py
def add_ten():
    ten = 10
    def add(num):
        return num + ten
    return add

closure_result = add_ten()
print(closure_result(20))
print(closure_result(40))


View:
output.txt
30
50


add_ten() returns the inner function add. add still sees ten = 10 after add_ten has finished. 20 + 10 is 30. 40 + 10 is 50.

Python Decorators

A decorator is a design pattern in Python that allows a user to add new functionality to an existing object without modifying its structure. Decorators are usually called before the definition of a function you want to decorate.

Creating Decorators

To create a decorator function, we need an outer function with an inner wrapper function.

Example:
example.py
# Normal function
def greeting():
    return 'Welcome to Python, Priya'

def uppercase_decorator(function):
    def wrapper():
        func = function()
        make_uppercase = func.upper()
        return make_uppercase
    return wrapper

g = uppercase_decorator(greeting)
print(g())


View:
output.txt
WELCOME TO PYTHON, PRIYA


The same idea with the @ syntax. @uppercase_decorator means: pass greeting into uppercase_decorator and replace greeting with the wrapper.
example.py
def uppercase_decorator(function):
    def wrapper():
        func = function()
        make_uppercase = func.upper()
        return make_uppercase
    return wrapper

@uppercase_decorator
def greeting():
    return 'Welcome to Python, Priya'

print(greeting())


View:
output.txt
WELCOME TO PYTHON, PRIYA


uppercase_decorator is a higher order function: it takes a function and returns a function.

Applying Multiple Decorators to a Single Function
example.py
# First Decorator
def uppercase_decorator(function):
    def wrapper():
        func = function()
        make_uppercase = func.upper()
        return make_uppercase
    return wrapper

# Second decorator
def split_string_decorator(function):
    def wrapper():
        func = function()
        splitted_string = func.split()
        return splitted_string
    return wrapper

# Decorators will be executed from bottom to top
@split_string_decorator
@uppercase_decorator     # order matters — .upper() does not work on a list
def greeting():
    return 'Welcome to Python'
print(greeting())


View:
output.txt
['WELCOME', 'TO', 'PYTHON']


Closest decorator runs first: uppercase_decorator turns the string to uppercase, then split_string_decorator splits it. If you swap the two lines, .upper() would be called on a list and would fail.

Accepting Parameters in Decorator Functions

Most of the time we need our functions to take parameters, so we might need to define a decorator that accepts parameters.
example.py
def decorator_with_parameters(function):
    def wrapper_accepting_parameters(para1, para2, para3):
        function(para1, para2, para3)
        print("I live in {}".format(para3))
    return wrapper_accepting_parameters

@decorator_with_parameters
def print_full_name(first_name, last_name, country):
    print("I am {} {}. I love to teach.".format(
        first_name, last_name))

print_full_name("Priya", "Rao", "India")


View:
output.txt
I am Priya Rao. I love to teach.
I live in India


The wrapper receives the same three arguments as print_full_name. It calls the original function, then prints one extra line using country.

Built-in Higher Order Functions

Some of the built-in higher order functions that we cover in this part are map(), filter, and reduce. sorted() is also a higher order function when you pass key=. Lambda function can be passed as a parameter and the best use case of lambda functions is in functions like map, filter, reduce, and sorted.




  #
  Function
  What it does
  Example
  View





  1
  map(fn, seq)
  Apply fn to every item
  list(map(lambda n: n * 2, [10, 20, 30]))
  [20, 40, 60]



  2
  filter(fn, seq)
  Keep items where fn is true
  list(filter(lambda n: n > 20, [10, 20, 30, 40]))
  [30, 40]



  3
  reduce(fn, seq)
  Fold the sequence into one value
  reduce(lambda a, b: a + b, [10, 20, 30])
  60



  4
  sorted(seq, key=fn)
  Return a new sorted list
  sorted([40, 10, 30, 20])
  [10, 20, 30, 40]




reduce lives in functools. The other three are built-in.

1. map()

The map() function is a built-in function that takes a function and iterable as parameters.
example.py
# syntax
map(function, iterable)


Example:1
example.py
numbers = [10, 20, 30, 40, 50]  # iterable
def square(x):
    return x ** 2
numbers_squared = map(square, numbers)
print(list(numbers_squared))
# Lets apply it with a lambda function
numbers_squared = map(lambda x: x ** 2, numbers)
print(list(numbers_squared))


View:
output.txt
[100, 400, 900, 1600, 2500]
[100, 400, 900, 1600, 2500]


map returns a map object. Wrap it in list() to see the values. 10 ** 2 is 100, 20 ** 2 is 400, and so on.

Example:2
example.py
numbers_str = ['10', '20', '30', '40', '50']  # iterable
numbers_int = map(int, numbers_str)
print(list(numbers_int))


View:
output.txt
[10, 20, 30, 40, 50]


int is already a function, so you can pass it to map without writing a lambda.

Example:3
example.py
names = ['Priya', 'Rao', 'Hyderabad', 'Abraham']  # iterable

def change_to_upper(name):
    return name.upper()

names_upper_cased = map(change_to_upper, names)
print(list(names_upper_cased))

# Let us apply it with a lambda function
names_upper_cased = map(lambda name: name.upper(), names)
print(list(names_upper_cased))


View:
output.txt
['PRIYA', 'RAO', 'HYDERABAD', 'ABRAHAM']
['PRIYA', 'RAO', 'HYDERABAD', 'ABRAHAM']


What actually map does is iterating over a list. For instance, it changes the names to upper case and returns a new list.

2. filter()

The filter() function calls the specified function which returns boolean for each item of the specified iterable (list). It filters the items that satisfy the filtering criteria.
example.py
# syntax
filter(function, iterable)


Example:1
example.py
# Lets filter only even numbers
numbers = [10, 15, 20, 25, 30]  # iterable

def is_even(num):
    if num % 2 == 0:
        return True
    return False

even_numbers = filter(is_even, numbers)
print(list(even_numbers))


View:
output.txt
[10, 20, 30]


15 and 25 are in the list so the filter has odd numbers to drop. A list of only 10, 20, 30, 40, 50 would keep every item, which does not show the filter working.

Example:2
example.py
numbers = [10, 15, 20, 25, 30]  # iterable

def is_odd(num):
    if num % 2 != 0:
        return True
    return False

odd_numbers = filter(is_odd, numbers)
print(list(odd_numbers))


View:
output.txt
[15, 25]

example.py
# Filter long name
names = ['Priya', 'Rao', 'Hyderabad', 'Abraham']  # iterable
def is_name_long(name):
    if len(name) > 7:
        return True
    return False

long_names = filter(is_name_long, names)
print(list(long_names))


View:
output.txt
['Hyderabad']


Hyderabad has 9 characters. The other names are 7 characters or fewer.

3. reduce()

The reduce() function is defined in the functools module and we should import it from this module. Like map and filter it takes two parameters, a function and an iterable. However, it does not return another iterable, instead it returns a single value.

Example:1
example.py
from functools import reduce

numbers_str = ['10', '20', '30', '40', '50']  # iterable
def add_two_nums(x, y):
    return int(x) + int(y)

total = reduce(add_two_nums, numbers_str)
print(total)


View:
output.txt
150


reduce walks left to right: 10 + 20 is 30, plus 30 is 60, plus 40 is 100, plus 50 is 150. Same total from the integer list:
example.py
from functools import reduce
print(reduce(lambda a, b: a + b, [10, 20, 30, 40, 50]))


View:
output.txt
150


4. sorted()

sorted() returns a new list in order. It does not change the original sequence. Pass key= a function (often a lambda) to sort by something other than the raw value. Pass reverse=True for descending order.
example.py
# syntax
sorted(iterable)
sorted(iterable, reverse=True)
sorted(iterable, key=function)

example.py
scores = [40, 10, 50, 20, 30]
print(sorted(scores))
print(sorted(scores, reverse=True))
print(scores)


View:
output.txt
[10, 20, 30, 40, 50]
[50, 40, 30, 20, 10]
[40, 10, 50, 20, 30]


The last line is still the original order. sorted did not mutate scores.
example.py
names = ['Priya', 'Rao', 'Hyderabad', 'Abraham']
print(sorted(names))
print(sorted(names, key=len))
print(sorted(names, key=lambda n: n.lower()))


View:
output.txt
['Abraham', 'Hyderabad', 'Priya', 'Rao']
['Rao', 'Priya', 'Abraham', 'Hyderabad']
['Abraham', 'Hyderabad', 'Priya', 'Rao']


Default string sort is alphabetical. key=len sorts by character count: Rao (3), Priya (5), Abraham (7), Hyderabad (9). key=lambda n: n.lower() sorts without caring about uppercase.

5. lambda with map, filter, reduce, sorted

A lambda is the small function from Day 13. These four calls are the usual place to write one.
example.py
from functools import reduce

scores = [10, 20, 30, 40, 50]
print(list(map(lambda n: n * 2, scores)))
print(list(filter(lambda n: n > 20, scores)))
print(reduce(lambda a, b: a + b, scores))
print(sorted(scores, key=lambda n: -n))


View:
output.txt
[20, 40, 60, 80, 100]
[30, 40, 50]
150
[50, 40, 30, 20, 10]


map changes every item. filter keeps some items. reduce collapses the list to one value. sorted(..., key=lambda n: -n) orders by the opposite number, so the largest score comes first.
