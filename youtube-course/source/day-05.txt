
Lists

There are four collection data types in Python:


List: is a collection which is ordered and changeable (modifiable). Allows duplicate members.

Tuple: is a collection which is ordered and unchangeable or unmodifiable (immutable). Allows duplicate members.

Set: is a collection which is unordered, un-indexed and unmodifiable, but we can add new items to the set. Duplicate members are not allowed.

Dictionary: is a collection which is unordered, changeable (modifiable) and indexed. No duplicate members.


A list is a collection of different data types which is ordered and modifiable (mutable). A list can be empty or it may have different data type items.

Slicing Items from a List


Positive Indexing: We can specify a range of positive indexes by specifying the start, end and step. The return value will be a new list. (default values for start = 0, end = last item + 1, step = 1)

example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
all_fruits = fruits[0:4]
all_fruits = fruits[0:]
orange_and_mango = fruits[1:3]
orange_mango_lemon = fruits[1:]
every_second = fruits[::2]
print(all_fruits)
print(orange_and_mango)
print(orange_mango_lemon)
print(every_second)

scores = [10, 20, 30, 40, 50]
print(scores[0:5])
print(scores[1:4])
print(scores[::2])


View:
output.txt
['banana', 'orange', 'mango', 'lemon']
['orange', 'mango']
['orange', 'mango', 'lemon']
['banana', 'mango']
[10, 20, 30, 40, 50]
[20, 30, 40]
[10, 30, 50]


The end index is not included. fruits[1:3] is indexes 1 and 2. fruits[::2] takes every second item starting at 0.


Negative Indexing: We can specify a range of negative indexes by specifying the start, end and step. The return value will be a new list.

example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
all_fruits = fruits[-4:]
orange_and_mango = fruits[-3:-1]
orange_mango_lemon = fruits[-3:]
reverse_fruits = fruits[::-1]
print(all_fruits)
print(orange_and_mango)
print(orange_mango_lemon)
print(reverse_fruits)

scores = [10, 20, 30, 40, 50]
print(scores[-5:])
print(scores[-4:-1])
print(scores[::-1])


View:
output.txt
['banana', 'orange', 'mango', 'lemon']
['orange', 'mango']
['orange', 'mango', 'lemon']
['lemon', 'mango', 'orange', 'banana']
[10, 20, 30, 40, 50]
[20, 30, 40]
[50, 40, 30, 20, 10]


A negative step walks the list backwards.

Modifying Lists

A list is a mutable or modifiable ordered collection of items. Let us modify the fruit list.
example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
fruits[0] = 'avocado'
print(fruits)
fruits[1] = 'apple'
print(fruits)
last_index = len(fruits) - 1
fruits[last_index] = 'lime'
print(fruits)

scores = [10, 20, 30, 40, 50]
scores[0] = 15
scores[-1] = 55
print(scores)


View:
output.txt
['avocado', 'orange', 'mango', 'lemon']
['avocado', 'apple', 'mango', 'lemon']
['avocado', 'apple', 'mango', 'lime']
[15, 20, 30, 40, 55]


last_index must be len(fruits) - 1. fruits[len(fruits)] is out of range.

append, insert, remove, pop, clear, extend, reverse, and sort change the original list. copy, count, index, +, and sorted do not (the + result is a new list).

5. del

The del keyword removes the specified index and it can also be used to delete items within an index range. It can also delete the list completely.
example.py
# syntax
lst = ['item1', 'item2']
del lst[index]  # only a single item
del lst         # to delete the list completely

example.py
fruits = ['banana', 'orange', 'mango', 'lemon', 'kiwi', 'lime']
del fruits[0]
print(fruits)
del fruits[1]
print(fruits)
del fruits[1:3]
print(fruits)

scores = [10, 20, 30, 40, 50]
del scores[1:4]
print(scores)


View:
output.txt
['orange', 'mango', 'lemon', 'kiwi', 'lime']
['orange', 'lemon', 'kiwi', 'lime']
['orange', 'lime']
[10, 50]


del fruits[1:3] does not delete the item that used to be at index 3 of the original list. It deletes the current slice after the earlier deletes.

del fruits then print(fruits) raises NameError: name 'fruits' is not defined. That is expected. The companion script does not print after deleting the name, so it can finish.

7. copy()

It is possible to copy a list by reassigning it to a new variable in the following way: list2 = list1. Now list2 is a reference of list1. Any changes we make in list2 will also modify the original, list1. One way of avoiding that is using copy().
example.py
# syntax
lst = ['item1', 'item2']
lst_copy = lst.copy()

example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
fruits_copy = fruits.copy()
print(fruits_copy)

scores = [10, 20, 30, 40, 50]
scores_copy = scores.copy()
scores_copy.append(60)
print(scores)
print(scores_copy)


View:
output.txt
['banana', 'orange', 'mango', 'lemon']
[10, 20, 30, 40, 50]
[10, 20, 30, 40, 50, 60]


Changing the copy does not change the original.

Plus Operator (+)

13. sort()

To sort lists we can use the sort() method or the sorted() built-in function. The sort() method reorders the list items in ascending order and modifies the original list. If reverse is True, it will arrange the list in descending order.
example.py
# syntax
lst = ['item1', 'item2']
lst.sort()                # ascending
lst.sort(reverse=True)    # descending


Example:
example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
fruits.sort()
print(fruits)
fruits.sort(reverse=True)
print(fruits)

ages = [22, 19, 24, 25, 26, 24, 25, 24]
ages.sort()
print(ages)
ages.sort(reverse=True)
print(ages)

scores = [40, 10, 50, 20, 30]
scores.sort()
print(scores)
scores.sort(reverse=True)
print(scores)


View:
output.txt
['banana', 'lemon', 'mango', 'orange']
['orange', 'mango', 'lemon', 'banana']
[19, 22, 24, 24, 24, 25, 25, 26]
[26, 25, 25, 24, 24, 24, 22, 19]
[10, 20, 30, 40, 50]
[50, 40, 30, 20, 10]


14. sorted()

sorted() returns the ordered list without modifying the original list.
example.py
fruits = ['banana', 'orange', 'mango', 'lemon']
print(sorted(fruits))
print(fruits)
fruits = ['banana', 'orange', 'mango', 'lemon']
print(sorted(fruits, reverse=True))

scores = [40, 10, 50, 20, 30]
print(sorted(scores))
print(scores)


View:
output.txt
['banana', 'lemon', 'mango', 'orange']
['banana', 'orange', 'mango', 'lemon']
['orange', 'mango', 'lemon', 'banana']
[10, 20, 30, 40, 50]
[40, 10, 50, 20, 30]


After sorted(fruits), fruits is still in the original order.
