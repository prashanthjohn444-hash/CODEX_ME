# Brag Plan: Python 30 Days

## What is this project?
A 30-day Python learning lab with lessons, a progress dashboard, mind maps, and a Day 1 lesson that runs a real `hello.py` file.

## The angle
The beginner's first Python win is tiny and concrete: the shell gives `30`, the file gives nothing until you write `print(10 + 20)`. Build the reel around that aha moment rather than promising fluency in 30 days. This is a course teaser, not a claim that all 30 videos have shipped.

## Hook (first 2–3 seconds)
Giant `10 + 20` on a dark code surface; the answer `30` snaps in, then the question: `Why did my file say nothing?`

## Key moments
- Show the actual Day 1 VS Code code capture, cropped to exclude private machine paths.
- Show the source lab's distinctive 30-day navigation, Foundations module, and lesson/dashboard styling as a reconstructed vertical interface.
- Change the file to `print(10 + 20)` and let the result `30` resolve the puzzle.

## Outro
`YOUR FIRST FILE. YOUR FIRST WIN.` followed by `PYTHON 30 DAYS · DAY 1`.

## User flow worth showing
Open Day 1 in the lab → write and run `hello.py` → see `Hello, Python!` and `30` in the terminal. The Day 1 production has real VS Code capture; the course UI is based on the local HTML lab, not a public site.

## Storyboard

### Scene 1 — The puzzle — 3s (0–3)
Large `10 + 20` and `30`, then `WHY DID MY FILE SAY NOTHING?` The answer remains long enough to read. Sequential/interaction: code cursor lands; audio: soft click into the groove. Transition: hard code-panel cut.

### Scene 2 — The file — 5s (3–8)
Real, privacy-cropped Day 1 VS Code capture of `print("Hello, Python!")` in an editor-shaped vertical panel, with the original lab's typography. The capture is from `broken_example.py`, so do not label this shot `hello.py`. Short header `A REAL FILE. A REAL RESULT.` Sequential/interaction: editor line lands, terminal opens. Audio: small UI click. Transition: clean slide.

### Scene 3 — The missing instruction — 5s (8–13)
Large editor/terminal recreation shows `10 + 20` produces no printed output in a saved file; then add `print(10 + 20)` and reveal `30`. The representation is illustrative but true to the Day 1 script. Sequential/interaction: one correction and one output. Audio: warm success cue on 30. Transition: crisp cut.

### Scene 4 — The path — 3s (13–16)
Lab-inspired `FOUNDATIONS / DAY 1 / RUN YOUR FIRST PYTHON FILE` stacked as a navigable course view, with mind-map and progress affordances sourced from the HTML. No fabricated completion progress. Audio: bed continues, minimal SFX. Transition: strong beat at ~15.82 into final card.

### Scene 5 — The invitation — 4s (16–20)
`PYTHON 30 DAYS` then `DAY 1 · RUN YOUR FIRST PYTHON FILE` / `YOUR FIRST FILE. YOUR FIRST WIN.` Settle and hold. Audio: subtle logo hit; music fades at end.

**Music mood:** upbeat and clean.

## Grounding & privacy
No live-course URL, release date, student outcomes, or completion statistic is claimed. The real screenshot is cropped before entering the project so the local Windows username and filesystem path do not appear or ship.
